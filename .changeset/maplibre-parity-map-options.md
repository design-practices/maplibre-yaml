`config:` map options follow MapLibre 6.14–6.16's shapes. `dragRotate` now also takes MapLibre's `DragRotateOptions` — `{ around: pointer }` turns and tilts around the point under the pointer, `{ around: center, movement: circular | linear }` replaces the deprecated `aroundCenter` — and a changed `dragRotate` in a live document is applied in place through the handler instead of rebuilding the map. `maxBounds` may leave longitude open the way `setMaxBounds` takes it from maplibre-gl 6.16, `[-.inf, south, .inf, north]` (either bounds form), to limit only how far north and south readers can go; a half-open longitude is refused in MapLibre's own words at the `maxBounds` line. On a 6.14+ runtime the document's `state:` defaults are handed to the `Map` constructor as `globalState`, so the first frame already reads them; older runtimes keep the `setGlobalStateProperty` path. Each shape has a runtime floor (6.15, 6.16, 6.14): below it the map still does the nearest right thing — `dragRotate: true`, the latitude limits with longitude closed at ±180, the setter path — and says so once in the console. `transformStyle` and `globalState` are recognised as MapLibre map options, so a host's config object no longer draws an "Unknown key" warning; `globalState` under `config:` (or `runtime.map:`) is told that `state:` is the place.
