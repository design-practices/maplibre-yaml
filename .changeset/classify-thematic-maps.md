Thematic maps from YAML: a layer's new `classify:` block makes a choropleth, graduated symbols or a category map without hand-writing a `step`/`match` expression. Give explicit `breaks:` (MapLibre `step` convention: n breaks, n + 1 classes, a value equal to a break takes the class above), or `method: quantile | equal | jenks` with `classes:` to compute them from a GeoJSON source's data when it loads (vector tile sources take explicit breaks; validation explains why), or `categories:` for a `match` with an `other:` colour. Colours come from a named palette — the ColorBrewer set, `viridis`, `cividis`, `okabe-ito`, case-insensitive with did-you-mean — or a `colors:` list; `radius:` sizes circles per class. Missing, empty and non-numeric values draw a `noData:` colour (light grey by default) or are hidden, instead of the black MapLibre paints when a `step` input is null or a string; numeric strings from CSV-derived GeoJSON are read as numbers. The map and story legends list each class with its real edges, formatted with `Intl` and MapLibre `number-format` option names. It compiles to plain MapLibre (class `exports`) and records the classes in the layer's `metadata["maplibre-yaml:classify"]`, in v1 and v2 alike; `mlym emit` bakes computed breaks into the style, loading a `url:` source's data at export and failing clearly when it cannot. `<ml-map>` fires `ml-map:layer-classified` with the classes as drawn.
