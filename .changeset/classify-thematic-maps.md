Thematic maps from YAML: a layer's new `classify:` block makes a choropleth, graduated symbols or a category map without hand-writing a `step`/`match` expression. Give explicit `breaks:` (MapLibre `step` convention: n breaks, n + 1 classes, a value equal to a break takes the class above), or `method: quantile | equal | jenks` with `classes:` to compute them from a GeoJSON source's data when it loads (vector tile sources take explicit breaks; validation explains why), or `categories:` for a `match` with an `other:` colour. Map a rate instead of a count with `normalize:` (and `multiply:`, e.g. `100000` for "per 100,000"): the division is guarded, so a missing, zero or non-numeric divisor is no data rather than Infinity, and breaks and legend labels are in the rate's units. Colours come from a named palette — the ColorBrewer set, `viridis`, `cividis`, `okabe-ito`, case-insensitive with did-you-mean — or a `colors:` list; `radius:` sizes circles per class. Missing, empty and non-numeric values draw a `noData:` colour (light grey by default) or are hidden, instead of the black MapLibre paints when a `step` input is null or a string; numeric strings from CSV-derived GeoJSON are read as numbers. A map or story with a classified layer gets a legend automatically, even without a `legend:` block (`legend: false` turns it off), listing each class with its real edges, formatted with the shared `formatNumber` (MapLibre `number-format` option names, the page's language by default), with "No data"/"Other" lines translatable as `maplibre-yaml.Classify.NoData`/`.Other` in `locale:`; the Astro `FullPageMap` no longer warns that such a map has no legend entries. It compiles to plain MapLibre (class `exports`) and records the classes in the layer's `metadata["maplibre-yaml:classify"]`, in v1 and v2 alike; `mlym emit` bakes computed breaks into the style, loading a `url:` source's data at export and failing clearly when it cannot. `<ml-map>` fires `ml-map:layer-classified` with the classes as drawn.
