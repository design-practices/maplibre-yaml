A new `grid` source type declares a regular raster field on a latitude/longitude grid (elevation, temperature, density, a current, any scalar or vector field) that page code reads as numbers rather than MapLibre draws: `type: grid` with a `url`, an `encoding` (`scalar-r` or `rg-uv` for 8-bit PNGs scaled by `range`, `nullschool-json`, or `geotiff` in EPSG:4326), the field's geometry as MapLibre-ordered `bounds: [west, south, east, north]` or node `grid: { nx, ny, lo1, la1, dx, dy }`, and optional `units`, `nodata`, `bands` and `attribution`. The file is fetched and decoded once from an on-demand chunk, so pages without a grid pay nothing. `<ml-map>` and `MapRenderer` gain `getGrid(id)` (the field, or `undefined` before decode), `gridReady(id)` (a promise for it) and `hasGrid(id)` (a synchronous `boolean`, true whenever the applied document declares a grid source of that id, regardless of decode state, so a caller can tell "not yet decoded" from "no such source" without awaiting), and the element fires `ml-map:source-loaded` with `{ sourceId }` when a grid is decoded; `<ml-scrollytelling>` forwards `getGrid`, `gridReady` and `hasGrid` to its map. The field exposes `kind`, `units`, `bounds`, `grid`, `wraps`, `nx`, `ny`, `sample(lngLat)` (a number, `{ u, v, speed }`, or `null` for missing data or outside the grid, bilinear with date-line wrap), `contains(position)` (a `boolean`, true when the position falls inside the grid, so a `null` from `sample()` can be read as "outside" rather than "missing data"), `rescale(range)` and `values()`. Under live document updates a changed `url` swaps the field atomically after decode, a changed `range` or `units` rescales without a fetch, and a changed `encoding` or geometry decodes again. A module-level cache keeps a decoded field across identical fetches, bounded by both a 16-entry limit and `GRID_CACHE_MAX_BYTES`, a 256 MB budget on retained decoded bytes. Validation checks the cross-key rules (one geometry form, `range` on the byte encodings only, `nodata` shape per encoding, `format:` pointing at `encoding:`) and rejects a layer drawn over a grid, since no layer type draws one yet; `rg-uv` now requires an RGB or RGBA image (a grayscale or grayscale+alpha PNG is refused with an encoding notice), a `nodata` rule naming a channel the image lacks is an error rather than silently ignored, and a nullschool header whose rows run south to north is refused, while a geographic GeoTIFF with no explicit EPSG GeoKey is accepted as longitude/latitude. `mlym emit` leaves a grid out of the exported `sources`, keeps its declaration under `metadata["maplibre-yaml:grid-sources"]`, and reports a `contract` warning, so `--strict` passes. New exports: `GridSourceSchema`, the `GridSourceConfig` type, the `GridField` type, the `FailureFormat` type, `lowerGridSource` and `GRID_SOURCES_METADATA_KEY`.
