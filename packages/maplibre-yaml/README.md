# maplibre-yaml

An alias for [`@maplibre-yaml/cli`](https://www.npmjs.com/package/@maplibre-yaml/cli), the maplibre-yaml command line.

```bash
npx maplibre-yaml validate my-map.yaml
```

It installs `@maplibre-yaml/cli` and runs it, so every command and flag is the same. For projects, install the CLI itself:

```bash
npm install --save-dev @maplibre-yaml/cli
```

Docs: https://docs.maplibre-yaml.org
