### `classify:`

Colours (and, on circle layers, sizes) features by class — a choropleth,
graduated symbols, or a category map — without writing the `step`/`match`
expression or the legend by hand. Fill, line, circle, fill-extrusion and
symbol layers. Full guide: [Thematic maps](/guides/thematic-maps/).

| Key | Type | Description |
| --- | --- | --- |
| `field` | string | **Required.** The feature property to classify. |
| `breaks` | number[] | Class thresholds, as MapLibre `step`: n breaks make n + 1 classes; a value equal to a break takes the class above it. Strictly ascending. |
| `method` | `quantile` \| `equal` \| `jenks` | Compute the breaks from the data instead — **GeoJSON sources only** (a vector tile source never holds the whole dataset). |
| `classes` | integer 2–12 | How many classes `method:` computes. Default 5. |
| `categories` | `{ value: colour }` \| list | Categorical classes (compiles to `match`): a map of value → colour, or a list of values coloured from `palette:`/`colors:`. |
| `palette` | string | A palette name, case-insensitive: ColorBrewer (`Blues`, `YlGnBu`, `RdBu`, `Set2` …), `viridis`, `cividis`, `okabe-ito`. Default `YlGnBu` (numeric), `okabe-ito` (categories). |
| `colors` | colour[] | Your own colours instead of a palette: one per class (or per listed category). |
| `reverse` | boolean | Flip the palette. |
| `property` | string | The colour paint property to drive. Default: `fill-color` / `line-color` / `circle-color` / `fill-extrusion-color` / `text-color`. |
| `radius` | number[] | Circle layers: one `circle-radius` per class (graduated symbols). |
| `noData` | colour \| `hide` | Features whose value is null, missing, empty or not a number. Default light grey `#cccccc`. |
| `other` | colour \| `hide` | Categories not listed. Default grey `#969696`. |
| `format` | object | Legend number format, with MapLibre `number-format` names: `locale`, `currency`, `unit`, `min-fraction-digits`, `max-fraction-digits`. |

Exactly one of `breaks:`, `method:` or `categories:`. The compiled
expression owns its paint property: `classify:` and the same property under
`paint:` on one layer is an error. Export class: `exports` — the emitted
style carries the compiled expression, and the layer's
`metadata["maplibre-yaml:classify"]` records the classes.

```yaml
type: map
id: classify-reference
config:
  center: [-75.19, 39.936]
  zoom: 12
  mapStyle: "https://tiles.openfreemap.org/styles/positron"
legend: {}
layers:
  - id: income
    type: fill
    source:
      type: geojson
      url: /data/classify/sample-tracts.geojson
    label: Median household income
    classify:
      field: median_income
      breaks: [40000, 60000, 80000, 100000]
      palette: Blues
      noData: hide
    paint:
      fill-opacity: 0.85
```

### `effect:` (experimental)

:::caution[Experimental]
`effect:` and `@maplibre-yaml/effects` are experimental in 0.7: the key's
params and the effects API may change in a minor release.
:::

An `effect:` block names a registered effect and carries its params flat
beside `type`. The layer it sits on stays a complete, ordinary layer — it is
what renders without the effects package, under an unsupported projection,
and in the exported style.

| Key | Type | Description |
| --- | --- | --- |
| `type` | string | A registered effect: `tonal-hatch` or `blueprint` built in, or one page JavaScript registered. |
| *any other key* | per effect | The effect's params, validated against its schema when `@maplibre-yaml/effects` is loaded. |

Built-in params:

| Effect | Layer type | Params (defaults) |
| --- | --- | --- |
| `tonal-hatch` | `fill-extrusion` | `ink` (`#4d4d4e`), `paper` (`#f9f3e3`), `atlas` (`hatch-atlas` — an `images:` name), `gain` (`0.72`), `outline` (`0.85`), `exaggerate` (`false`) |
| `blueprint` | `fill-extrusion` | `line` (`#cfeeff`), `ground` (`#1a56b0`), `grid` (`4` metres), `gain` (`0.72`) |

```yaml
type: map
id: blueprint-example
config:
  center: [-74.0118, 40.7075]
  zoom: 15.9
  pitch: 60
  mapStyle: "https://tiles.openfreemap.org/styles/liberty"
sources:
  omt:
    type: vector
    url: "https://tiles.openfreemap.org/planet"
layers:
  - id: buildings
    type: fill-extrusion
    source: omt
    source-layer: building
    paint:
      fill-extrusion-color: "#1a56b0"
      fill-extrusion-height: ["coalesce", ["get", "render_height"], 10]
    effect:
      type: blueprint
      grid: 4
```

Without the package, validation reports one `unimplemented` warning per
effect (never an error) and the layer renders statically. With it, a bad
param is a positioned parse error. On `mlym emit`, each effect is one
`lossy` warning: `--strict` refuses, `--with-fallbacks` ships the static
layer ([export classes](/guides/export-classes/)). Full guide:
[Effects](/guides/effects/).

## Line Layer

Draws `LineString` features, and polygon outlines: routes, rivers, borders.
Spec: [`line`](https://maplibre.org/maplibre-style-spec/layers/#line).

```yaml
type: map
id: rivers
config:
  center: [-95, 40]
  zoom: 3
  mapStyle: "https://tiles.openfreemap.org/styles/liberty"
layers:
  - id: rivers
    type: line
    source:
      type: geojson
      url: "https://raw.githubusercontent.com/nvkelso/natural-earth-vector/master/geojson/ne_110m_rivers_lake_centerlines.geojson"
    layout:
      line-cap: round
      line-join: round
    paint:
      line-color: "#2563eb"
      line-width: 3
```

## Fill Layer

Shades polygon areas: regions, parcels, choropleths.
Spec: [`fill`](https://maplibre.org/maplibre-style-spec/layers/#fill).

```yaml
type: map
id: states
config:
  center: [-98, 39]
  zoom: 3
  mapStyle: "https://tiles.openfreemap.org/styles/liberty"
layers:
  - id: states
    type: fill
    source:
      type: geojson
      url: "https://maplibre.org/maplibre-gl-js/docs/assets/us_states.geojson"
    paint:
      fill-color: "#22c55e"
      fill-opacity: 0.4
      fill-outline-color: "#166534"
```

## Fill-Extrusion Layer

Extrudes polygons into 3D, usually buildings. Tilt the camera with `pitch` to
see the height.
Spec: [`fill-extrusion`](https://maplibre.org/maplibre-style-spec/layers/#fill-extrusion).

```yaml
type: map
id: buildings-3d
config:
  center: [-74.0118, 40.7075]
  zoom: 15.5
  pitch: 60
  mapStyle: "https://tiles.openfreemap.org/styles/liberty"
sources:
  omt:
    type: vector
    url: "https://tiles.openfreemap.org/planet"
layers:
  - id: buildings
    type: fill-extrusion
    source: omt
    source-layer: building
    paint:
      fill-extrusion-color: "#f59e0b"
      fill-extrusion-height: ["coalesce", ["get", "render_height"], 10]
      fill-extrusion-opacity: 0.8
```

## Symbol Layer

Draws text labels and icons at points (or along lines). Text is drawn with
the basemap style's fonts (its `glyphs`), so `text-font` must name a font
that style has: the OpenFreeMap styles have `Noto Sans Regular`, `Noto Sans
Bold` and `Noto Sans Italic`. A label layer without `text-font` borrows a
font the basemap style's own labels use (from core 0.8.1): its "Regular"
font if it has one (`Noto Sans Regular` on OpenFreeMap), otherwise the one
its labels use most, so the text loads from the basemap's glyphs; if the basemap has no labels to borrow
from, the console says so once and MapLibre falls back to `Open Sans
Regular`, which most styles lack. Set `text-font` to choose the font.
Spec: [`symbol`](https://maplibre.org/maplibre-style-spec/layers/#symbol).

```yaml
type: map
id: city-labels
config:
  center: [10, 30]
  zoom: 1.5
  mapStyle: "https://tiles.openfreemap.org/styles/liberty"
layers:
  - id: cities
    type: symbol
    source:
      type: geojson
      url: "https://raw.githubusercontent.com/nvkelso/natural-earth-vector/master/geojson/ne_110m_populated_places_simple.geojson"
    layout:
      text-field: ["get", "name"]
      text-font: ["Noto Sans Regular"]
      text-size: 12
    paint:
      text-color: "#7c2d12"
      text-halo-color: "#ffffff"
      text-halo-width: 1.5
```

## Heatmap Layer

Turns many points into a density surface.
Spec: [`heatmap`](https://maplibre.org/maplibre-style-spec/layers/#heatmap).

```yaml
type: map
id: quake-heat
config:
  center: [-120, 37]
  zoom: 3
  mapStyle: "https://tiles.openfreemap.org/styles/liberty"
layers:
  - id: quakes-heat
    type: heatmap
    source:
      type: geojson
      url: "https://earthquake.usgs.gov/earthquakes/feed/v1.0/summary/all_week.geojson"
    paint:
      heatmap-weight: ["interpolate", ["linear"], ["get", "mag"], 0, 0, 6, 1]
      heatmap-radius: 20
      heatmap-opacity: 0.8
```

## Hillshade Layer

Shades terrain from a `raster-dem` (elevation) source.
Spec: [`hillshade`](https://maplibre.org/maplibre-style-spec/layers/#hillshade).

```yaml
type: map
id: rainier
config:
  center: [-121.76, 46.85]
  zoom: 10
  mapStyle: "https://tiles.openfreemap.org/styles/liberty"
layers:
  - id: hills
    type: hillshade
    source:
      type: raster-dem
      tiles:
        - "https://s3.amazonaws.com/elevation-tiles-prod/terrarium/{z}/{x}/{y}.png"
      encoding: terrarium
      tileSize: 256
      maxzoom: 14
      attribution: "Terrain tiles: Mapzen/AWS Open Data"
    paint:
      hillshade-exaggeration: 0.6
      hillshade-shadow-color: "#2a3d4f"
```

## Raster Layer

Shows image tiles: satellite imagery, scanned maps, other providers' basemaps.
Spec: [`raster`](https://maplibre.org/maplibre-style-spec/layers/#raster).

```yaml
type: map
id: satellite
config:
  center: [12.5, 41.9]
  zoom: 9
  mapStyle: "https://tiles.openfreemap.org/styles/liberty"
layers:
  - id: imagery
    type: raster
    source:
      type: raster
      tiles:
        - "https://tiles.maps.eox.at/wmts/1.0.0/s2cloudless-2020_3857/default/g/{z}/{y}/{x}.jpg"
      tileSize: 256
      attribution: "Sentinel-2 cloudless by EOX IT Services GmbH (contains modified Copernicus Sentinel data 2020)"
    paint:
      raster-opacity: 0.85
```

## Background Layer

A single colour (or pattern) over the whole map. It has no `source`. Placed in
`layers:`, it draws above the basemap, so keep it translucent.
Spec: [`background`](https://maplibre.org/maplibre-style-spec/layers/#background).

```yaml
type: map
id: tinted
config:
  center: [-74.006, 40.7128]
  zoom: 11
  mapStyle: "https://tiles.openfreemap.org/styles/liberty"
layers:
  - id: wash
    type: background
    paint:
      background-color: "#1d3557"
      background-opacity: 0.25
```

## Color Relief Layer

Hypsometric tinting: each pixel of a `raster-dem` source is colored by its
elevation. `color-relief-color` is a color ramp over the `["elevation"]`
expression, the way `heatmap-color` ramps over `["heatmap-density"]`.
**Requires maplibre-gl 5.6 or later.**

| Paint property | Type | Description |
|----------------|------|-------------|
| `color-relief-color` | color expression | Ramp over `["elevation"]` (`interpolate` or `step`) |
| `color-relief-opacity` | number | Layer opacity (0-1) |

```yaml
type: map
id: relief
config:
  center: [11.45, 47.2]
  zoom: 10
  mapStyle: "https://tiles.openfreemap.org/styles/liberty"
layers:
  - id: relief
    type: color-relief
    source:
      type: raster-dem
      url: https://demotiles.maplibre.org/terrain-tiles/tiles.json
      tileSize: 256
    paint:
      color-relief-color:
        - interpolate
        - ["linear"]
        - ["elevation"]
        - 400
        - "rgb(4, 0, 108)"
        - 1500
        - "rgb(39, 144, 116)"
        - 3500
        - "rgb(215, 5, 13)"
```

On a runtime below 5.6, `<ml-map>` skips color-relief layers with one console
warning (a declared absence), and the rest of the document renders normally.
On export the layer compiles through verbatim. `mlym emit --target` below 5.6
reports it as lossy. See the [gallery example](/examples/gallery/add-a-color-relief-layer/).

## Popups

A layer's `interactive.click.popup` (and `interactive.hover.popup`, a preview
shown while the pointer is over a feature) describes the popup's content. See
[Layer Interactivity](/schema/interactivity/#layer-interactivity) for the rest
of the `interactive:` block.

This complete document shows the parts you will use most. Click a city to
open its popup:

```yaml
type: map
id: popup-demo
config:
  center: [-82, 41]
  zoom: 4
  mapStyle: "https://tiles.openfreemap.org/styles/liberty"
layers:
  - id: cities
    type: circle
    source:
      type: geojson
      data:
        type: FeatureCollection
        features:
          - type: Feature
            geometry: { type: Point, coordinates: [-74.006, 40.7128] }
            properties:
              name: "New York"
              population: 8336817
              nickname: "The Big Apple"
          - type: Feature
            geometry: { type: Point, coordinates: [-87.623, 41.881] }
            properties:
              name: "Chicago"
              population: 2693976
    paint:
      circle-radius: 10
      circle-color: "#ef4444"
      circle-stroke-width: 2
      circle-stroke-color: "#ffffff"
    interactive:
      hover:
        cursor: pointer
      click:
        popup:
          - h3:
              - property: name
          - p:
              - str: "Population: "
              - property: population
                format: ",.0f"
          - p:
              - str: "Nickname: "
              - property: nickname
                else: "none recorded"
          - p:
              - href: "https://en.wikipedia.org/wiki/List_of_United_States_cities_by_population"
                text: "Largest US cities"
```

New York's popup reads "Population: 8,336,817" and "Nickname: The Big Apple".
Chicago has no `nickname`, so its popup shows "Nickname: none recorded".

### Structure

The popup is a list. Each entry is one HTML element: the key is the tag, and
the value is a list of **items** whose output is joined inside that element.
`- h3: [{ property: name }]` becomes `<h3>New York</h3>`.

**Tags:** `h1`–`h6`, `p`, `span`, `div`, `strong`, `em`, `code`, `pre`, `a`,
`img`, `ul`, `ol`, `li`, `blockquote`, `hr`, `br`. Any other key is skipped
with a console warning. Elements do not nest: a `ul:` entry cannot contain
`li:` entries.

### Items

Each item is one of these:

| Item | Output |
|------|--------|
| `str: "Population: "` | The text as written |
| `property: population` | The feature's `population` property |
| `property: …` plus `else: "n/a"` | `else` is shown when the property is missing or `null` (without `else`, nothing is shown) |
| `property: …` plus `format: ",.0f"` | Formats a number. `,` adds thousands separators and `.Nf` keeps N decimal places: `",.0f"` gives `8,336,817`, `".2f"` gives `0.12`. Text values are shown unchanged |
| `href: "https://…"` plus `str: "Read more"` (or `text:`) | A link with that text. Without `str` or `text`, the URL is the link text. See [Links](#links) |
| `src: "https://…/photo.jpg"` plus `alt: "…"` | An image |

Put links and images inside `p:` (or `div:`):

```yaml
popup:
  - p:
      - str: "New York on Wikipedia"
        href: "https://en.wikipedia.org/wiki/New_York_City"
  - p:
      - src: "https://maplibre.org/img/maplibre-logo-big.svg"
        alt: "MapLibre logo"
```

Wrapping a link in `a:` or an image in `img:` instead gives the same result.

### Links

A link item needs `href`. Its text is `str` or `text` (if both are given,
`text` wins), and the URL itself when neither is given.

- **`href`** is an absolute URL (`https://…`, `http://…`, `mailto:…`, `tel:…`)
  or a relative path (`/about`, `./notes.html`, `notes.html`, `#top`). A link
  with any other scheme, such as `javascript:`, is shown as plain text and the
  console logs a warning.
- **`target`** chooses where the link opens: `_blank` (the default, a new tab,
  with `rel="noopener noreferrer"`), `_self` (this tab), `_parent` or `_top`.
  Any other value fails validation with
  `target must be one of: _blank, _self, _parent, _top`.

```yaml
popup:
  - p:
      - str: "Back to the class page"
        href: "/"
        target: _self
```

The link URL is fixed text. An item cannot build a URL from a feature
property.

### Escaping and `!html`

Feature property values and `str` text are always HTML-escaped. A property
containing `<b>bold</b>` shows those characters literally, so data cannot
inject markup into your page.

A `str` tagged `!html` (`- str: !html "<em>styled</em>"`) asks for raw
markup. It is rendered as markup only under a **trusted** capability policy.
`<ml-map>` is untrusted by default, so there the value is shown as escaped
text and the console logs a warning.
