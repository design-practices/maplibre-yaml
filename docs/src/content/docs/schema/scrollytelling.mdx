Scrollytelling creates immersive narrative map experiences where the map transitions between chapters as users scroll through content. Perfect for data journalism, storytelling, and guided tours.

## Showing a story

A story is a YAML file. One engine shows it, from `@maplibre-yaml/core`, in
whichever kind of site you have.

**A plain HTML page** (no build step; maplibre-yaml from a CDN): the
`<ml-scrollytelling>` element. Load `@maplibre-yaml/core/register` as in
[Scrollytelling in plain HTML](/integrations/scrollytelling-html/), then:

```html
<ml-scrollytelling src="story.yaml"></ml-scrollytelling>
```

The YAML can also sit inline in a `<script type="text/yaml">` child, or be
assigned from JavaScript (`element.story = {...}`).

**An Astro site**: the [`<Scrollytelling>`](/integrations/astro/#scrollytelling-component)
component, which renders the same element. Load and validate the story at build
time, or let the browser fetch it:

```astro
---
import { Scrollytelling, loadScrollytellingConfig } from '@maplibre-yaml/astro';
const story = await loadScrollytellingConfig('./src/stories/my-story.yaml');
---
<Scrollytelling config={story} />
<!-- or, from public/: <Scrollytelling src="/stories/my-story.yaml" /> -->
```

Both show the same thing for the same file: a sticky map with the chapters
scrolling over it, the camera moves, layer changes and actions below, the
chapter rail, themes, and reduced-motion handling. Check a story without a
browser with `npx maplibre-yaml validate story.yaml`.

## Scrollytelling Block Structure

A story file is a standalone YAML document with `type: scrollytelling` at the
top level. That is what `<ml-scrollytelling src>`, `loadScrollytellingConfig`,
`<Scrollytelling src>`, a stories content collection and
`npx maplibre-yaml validate` all read, and
every full example on this page is written that way, ready to paste into a
file of its own. (Only inside a site file's `pages:` → `blocks:` list is a
story a list item, `- type: scrollytelling`; see
[Simple Story](#simple-story).)

```yaml no-validate
type: scrollytelling
id: story
config:              # Base map configuration
  center: [lng, lat]
  zoom: 2
  mapStyle: "..."
theme: light         # Visual theme
showMarkers: false   # Chapter navigation rail
layers: [...]        # Persistent layers
chapters: [...]      # Story chapters (required)
footer: "..."        # Optional footer HTML
# Optional, as on a type: map document: sources, markers, legend,
# state + parameters, images, controls, terrain, sky, projection, light
```

## Scrollytelling Properties

| Property | Type | Required | Default | Description |
|----------|------|----------|---------|-------------|
| `type` | `"scrollytelling"` | Yes | - | Block type |
| `id` | string | Yes | - | Unique identifier |
| `config` | object | Yes | - | Base map configuration |
| `chapters` | array | Yes | - | Story chapters (min: 1) |
| `theme` | `"light"` \| `"dark"` | No | `"light"` | Visual theme |
| `showMarkers` | boolean | No | `false` | Show a navigation rail: one dot per chapter at the right edge of the page, which readers can click to jump to a chapter. It does not put markers on the map |
| `markerColor` | string | No | - | Fill color of the rail's dots. Unset, the dots are white with a dark outline and the current one is larger and dark, which stand out on any basemap |
| `cameraOffset` | boolean | No | `true` | Offset the camera so each chapter's `center` isn't under its card (beside a left/right card, above a centred one, above the card on a phone). `false` centres it in the whole map. A chapter's own `padding` always wins |
| `layers` | array | No | `[]` | Persistent layers |
| `footer` | string | No | - | Footer HTML content |
| `legend` | object | No | - | The story's legend, pinned above the cards (see [The legend](#the-legend)): the map legend's `title` and `items`, an optional `position`, and `collapsed: auto` (default), `true` or `false` |
| `sources`, `markers`, `state`, `parameters`, `popups`, `images`, `controls`, `terrain`, `sky`, `projection`, `light` | - | No | - | The story's map takes every map-level key a [`type: map` document](/schema/map-config/) does, with the same schema (see [Map-level keys](#map-level-keys)) |

## Chapters

Each chapter represents one section of the narrative. As users scroll, the map smoothly transitions between chapters.

### Chapter Structure

```yaml
chapters:
  - id: intro
    title: "Introduction"
    description: "Welcome to our story."
    center: [-74.006, 40.7128]
    zoom: 12
    pitch: 0
    bearing: 0
    animation: flyTo
    alignment: center
```

### Required Chapter Properties

| Property | Type | Description |
|----------|------|-------------|
| `id` | string | Unique chapter identifier |
| `title` | string | Chapter title |
| `center` | [number, number] | Map center [longitude, latitude] |
| `zoom` | number | Zoom level (0-24) |

Each chapter needs its own `id`: copying a chapter and keeping its `id` is a
validation error naming both lines (`Two chapters have id "the-met" (lines 96
and 144)`). Give layers their own ids too: a repeated layer id warns, and the
map draws the first layer with that id and skips the repeat. A chapter's `layers.show` /
`layers.hide` or action `layer:` that is a near miss of one of the story's
layers (`walking` for `walk`) gets a did-you-mean warning; a name unlike any
of them is taken to be a basemap layer and is not flagged.

### Optional Chapter Properties

#### Content

| Property | Type | Description |
|----------|------|-------------|
| `description` | string | Chapter text as HTML (`<p>`, `<strong>`, `<a href>`…). Markdown is not converted: `**bold**` shows literally |
| `image` | string | Hero image: a full `https://` URL, or a path to a file in your site's `public/` folder such as `/images/fuji.jpg` |
| `video` | string | Video, given the same way as `image` |

#### Camera

| Property | Type | Default | Range | Description |
|----------|------|---------|-------|-------------|
| `pitch` | number | `0` | 0-85 | Camera tilt angle |
| `bearing` | number | `0` | -180 to 180 | Camera rotation |
| `speed` | number | `0.6` | 0-2 | Animation speed multiplier |
| `curve` | number | `1` | 0-2 | Animation curve (0=linear, 1=default, 2=steep) |
| `animation` | string | `"flyTo"` | - | Animation type: `flyTo`, `easeTo`, `jumpTo` |
| `rotateAnimation` | boolean | `false` | - | Continuous rotation |
| `spinGlobe` | boolean | `false` | - | Slowly pan the camera westward while the chapter is active (paused under `prefers-reduced-motion`). Globe itself is the map-level `projection: { type: globe }` |

#### Layout

| Property | Type | Default | Description |
|----------|------|---------|-------------|
| `alignment` | string | `"center"` | Content position: `left`, `right`, `center`, `full` |
| `hidden` | boolean | `false` | Hide chapter content (map-only) |
| `padding` | number or `{ top, right, bottom, left }` | — | Camera padding in pixels for this chapter, used as written instead of the automatic offset that keeps `center` clear of the card |

## Chapter Actions

Execute actions when entering or exiting chapters.

### Action Types

| Action | Description |
|--------|-------------|
| `setFilter` | Update layer filter |
| `setPaintProperty` | Update layer paint property |
| `setLayoutProperty` | Update layer layout property |
| `fitBounds` | Fit map to bounds |
| `custom` | Custom action (application-defined) |

### Set Filter

```yaml
- id: filtered
  title: "High Magnitude Events"
  center: [-120, 35]
  zoom: 6
  onChapterEnter:
    - action: setFilter
      layer: earthquakes
      filter: [">=", ["get", "magnitude"], 5]
  onChapterExit:
    - action: setFilter
      layer: earthquakes
      filter: null  # Clear filter
```

### Set Paint Property

```yaml
- id: highlight
  title: "Highlighted Buildings"
  center: [-74.006, 40.7128]
  zoom: 16
  onChapterEnter:
    - action: setPaintProperty
      layer: buildings
      property: fill-extrusion-color
      value: "#ff0000"
  onChapterExit:
    - action: setPaintProperty
      layer: buildings
      property: fill-extrusion-color
      value: "#aaaaaa"
```

### Set Layout Property

```yaml
- id: show-labels
  title: "Points of Interest"
  center: [-74.006, 40.7128]
  zoom: 14
  onChapterEnter:
    - action: setLayoutProperty
      layer: poi-labels
      property: visibility
      value: visible
  onChapterExit:
    - action: setLayoutProperty
      layer: poi-labels
      property: visibility
      value: none
```

### Fit Bounds

```yaml
- id: bounded
  title: "City Limits"
  center: [-74.006, 40.7128]
  zoom: 10
  onChapterEnter:
    - action: fitBounds
      bounds: [-74.3, 40.5, -73.7, 40.9]
      options:
        padding: 50
        duration: 2000
```

## Chapter Navigation Rail

`showMarkers: true` adds a navigation rail: a column of dots at the right edge
of the map, one per chapter. The active chapter's dot is highlighted, and
clicking a dot (or focusing it and pressing Enter) scrolls to that chapter; the
arrow keys, Home and End move along the rail.
The dots are white with a dark outline, and the current chapter's dot is
larger and filled dark with a white ring, so the rail stands out on light and
dark basemaps alike and the current chapter is marked by size and fill, not
colour alone. `markerColor` fills the dots with a color of your own; the dark
outline stays. Despite the name, nothing is drawn on the map itself; to mark
chapter locations on the map, add a layer.

```yaml
type: scrollytelling
id: marked-story
showMarkers: true
markerColor: "#ff0000"
config:
  center: [-96, 37]
  zoom: 3
  mapStyle: "https://basemaps.cartocdn.com/gl/positron-gl-style/style.json"
chapters:
  - id: location1
    title: "First Location"
    center: [-74, 40]
    zoom: 12

  - id: location2
    title: "Second Location"
    center: [-118, 34]
    zoom: 12
```

```yaml
    center: [0, 40]
    zoom: 4
```

## Map-level keys

A story's map is an ordinary map document, so everything a
[`type: map` document](/schema/map-config/) takes at its top level works in a
story too: named `sources:` shared by several layers, standalone `markers:`
with popups, a `legend:` (pinned above the cards, see [The legend](#the-legend)), the params panel (`state:` + `parameters:`),
`images:`, `controls:`, and the 3D and globe keys. They are validated with the
same schema, and a story layer's source takes the
[GeoJSON sugar](/schema/sources/#geojson-sugar) shorthands (`location:`,
`locations:`, `region:`, `route:`).

```yaml
type: scrollytelling
id: harbour-tour
config:
  center: [-74.01, 40.70]
  zoom: 12
  mapStyle: "https://tiles.openfreemap.org/styles/liberty"
sources:
  piers:
    type: geojson
    locations:
      - coordinates: [-74.017, 40.703]
        name: Battery Park
      - coordinates: [-73.997, 40.705]
        name: South Street Seaport
layers:
  - id: pier-dots
    type: circle
    source: piers
    paint:
      circle-radius: 8
      circle-color: "#0ea5e9"
markers:
  - at: [-74.0445, 40.6892]
    color: "#16a34a"
    popup:
      - h3:
          - str: Statue of Liberty
legend:
  title: Harbour tour
  items:
    - { color: "#0ea5e9", label: Pier, shape: circle }
chapters:
  - id: piers
    title: "The piers"
    center: [-74.01, 40.70]
    zoom: 13
  - id: liberty
    title: "Liberty Island"
    center: [-74.0445, 40.6892]
    zoom: 14
```

The story map's own pan and zoom gestures start off, so the reader's wheel and
finger scroll the story. Markers, popups, the legend and the params panel stay
clickable. To let readers move the map, set the gesture in `config:`
(`scrollZoom: true`, `dragPan: true`, ...), as on any map.

## The legend

A story's legend is pinned: it stays in one corner, above the chapter cards,
and never moves while the story scrolls.

- **Corner.** `position:` if you set one. Otherwise top-left (opposite the
  chapter rail), or top-right on a wide screen whose cards are all
  `alignment: left`.
- **Open or a button.** With `collapsed: auto` (the default) the legend is a
  compact button named after its `title` ("Legend" without one) on phones,
  upright or on their side, and on wide screens where cards pass its corner
  (cards on both sides, or full-width). It is open everywhere else, where no
  card ever reaches it. `collapsed: true` always starts it as a button;
  `collapsed: false` always starts it open.
- **Opening it.** The button opens the legend as a panel above the cards. It
  is not a dialog: the map and the page stay usable, Escape closes it and puts
  focus back on the button, and on a phone a tap outside closes it. A long
  legend scrolls inside the panel.

```yaml
legend:
  title: Harbour tour
  collapsed: auto        # true | false | auto
  # position: top-right  # optional; the default follows the cards
  items:
    - { color: "#0ea5e9", label: Pier, shape: circle }
```

A `slot="legend"` child of the story fills the same panel with your own markup
instead of the entries.

Everything else on the map stays put too. MapLibre's controls (scale bar,
attribution, zoom buttons), corner slots, the params panel and the on-map
notice sit in their corners under the cards: a card passes over a corner while
it scrolls by and rests clear of the bottom corners. On phones the attribution
stays a compact (i) button.

## Complete Examples

### Simple Story

A story can also be one block of a multi-page site file (a root document with
`pages:`). There, and only there, it is a list item under `blocks:`:

```yaml
pages:
  - path: "/story"
    title: "Our Journey"
    blocks:
      - type: scrollytelling
        id: journey
        config:
          center: [0, 20]
          zoom: 2
          mapStyle: "https://demotiles.maplibre.org/style.json"
        chapters:
          - id: start
            title: "The Beginning"
            description: "Our story starts here."
            center: [0, 20]
            zoom: 2

          - id: destination
            title: "The Destination"
            description: "And ends here."
            center: [100, 30]
            zoom: 5
```

## TypeScript Types

```typescript
import {
  type ScrollytellingBlock,
  type Chapter,
  type ChapterAction,
  type ChapterLayers
} from '@maplibre-yaml/core/schemas';

const chapter: Chapter = {
  id: "intro",
  title: "Introduction",
  description: "Welcome to our story",
  center: [-74.006, 40.7128],
  zoom: 12,
  pitch: 45,
  bearing: 0,
  animation: "flyTo",
  alignment: "center"
};

const action: ChapterAction = {
```
