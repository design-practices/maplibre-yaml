Map configuration defines the initial view, interaction settings, controls, and legends for map blocks. All configuration follows the [MapLibre GL JS API](https://maplibre.org/maplibre-gl-js/docs/API/).

## Map Config Structure

```yaml
- type: map
  id: my-map
  config:              # Map configuration
    center: [lng, lat]
    zoom: 12
    mapStyle: "..."
    pitch: 0
    bearing: 0
    # ... additional options
  state: {...}         # Runtime-tunable values (optional)
  parameters: {...}    # Control metadata for state keys → params panel (optional)
  markers: [...]       # Standalone DOM pins (optional)
  images: {...}        # Named images for icons and patterns (optional)
  layers: [...]        # Map layers
  controls: {...}      # Map controls (optional)
  legend: {...}        # Legend (optional)
```

## Required Properties

| Property | Type | Description |
|----------|------|-------------|
| `center` | [number, number] | Initial map center [longitude, latitude] |
| `zoom` | number | Initial zoom level (0-24) |
| `mapStyle` | string \| object | MapLibre style URL or style object |

### Example

```yaml
config:
  center: [-74.006, 40.7128]
  zoom: 12
  mapStyle: "https://demotiles.maplibre.org/style.json"
```

## Runtime state and parameters

`state:` declares runtime-tunable values a map can change after it loads, read
from expressions via `global-state`. It is a document-root key — a sibling of
`config:`, not nested inside it — and it uses the MapLibre style spec's own
shape, `{ key: { default: value } }`:

```yaml
type: map
id: massing
state:
  scenario:
    default: built
config:
  center: [-73.98, 40.75]
  zoom: 12
layers:
  - id: buildings
    type: fill-extrusion
    source: parcels
    paint:
      fill-extrusion-height:
        - case
        - ["==", ["global-state", "scenario"], "built"]
        - ["get", "built_height"]
        - ["get", "zoned_height"]
```

`parameters:` carries the presentation metadata a control UI needs to render a
picker for a state key — the library owns the parameter's shape, the host owns
how it looks. It holds no `default`; the value lives in `state:`.

```yaml
parameters:
  scenario:
    label: Massing scenario
    type: enum
    values: [built, potential]
```

Declaring `parameters:` renders the built-in **params panel** (top-right, in
the same corner system as the legend): each entry becomes a control writing
its state key via `setGlobalStateProperty`, seeded from the key's `state:`
default. Each entry:

| Property | Type | Description |
|----------|------|-------------|
| `label` | string | Control caption (defaults to the state key) |
| `type` | string | `range`, `select` (alias `enum`), or `toggle`; unrecognized types render a labeled read-only row. Omitted: inferred — `values` present → select, boolean default → toggle |
| `values` | array | The options, for `select` — authored value types survive (a numeric enum writes numbers) |
| `min` / `max` | number | Bounds, for `range` (both required — a range without them renders read-only) |
| `step` | number | Increment, for `range` |

The panel also lists a **visibility checkbox for every layer with an
authored `label:`** (set `toggleable: false` to opt a labeled layer out).
The label is the opt-in on purpose: `toggleable` defaults to `true` on
every layer, so it cannot signal intent by itself. Layer toggles write
plain layout visibility and work on every supported runtime; parameter
controls need maplibre-gl ≥ 5.6 and degrade to one notice below it. Panel
writes are observable as `ml-map:parameter-change` and
`ml-map:layer-visibility` events.

:::note
`state` and `global-state` require **maplibre-gl 5.6.0 or later**, and are
supported on maplibre-gl JS only. When a document is compiled with `mlym emit`
for an older runtime — or for cross-renderer portability — the emitter inlines
each state key's default and drops the `state` block.
:::

## Markers

`markers:` places standalone DOM pins (`maplibregl.Marker`) — a document-root
key, a sibling of `config:`. Each entry:

| Property | Type | Description |
|----------|------|-------------|
| `at` | [number, number] | Marker position [longitude, latitude] (required) |
| `color` | color | Pin color (default pin only; ignored when `icon` is set) |
| `size` | number | Scale multiplier over MapLibre's default pin (1 = default) |
| `icon` | string | Image URL replacing the default pin |
| `popup` | popup content | Popup opened by clicking the marker — same structured content as [layer popups](/schema/interactivity/) |

```yaml
type: map
id: pins
config:
  center: [-73.98, 40.75]
  zoom: 12
markers:
  - at: [-73.985, 40.748]
    color: "#e63946"
    popup:
      - h3:
          - str: Empire State Building
```

Markers are a **fallback-class** construct on eject: `mlym emit
--with-fallbacks` lowers them to a symbol layer with generated pin sprites
(the pins render; dragging and popup content do not compile), and `--strict`
refuses marker documents. `icon:` URLs are fetched into the document sprite
at compile time, so ejected icon markers keep their images. See the [eject
classes reference](/guides/eject-classes/).

## Images

`images:` declares named images for symbol layers and patterns — a
document-root key, a sibling of `config:`. Each entry is a URL string or an
options object:

| Property | Type | Description |
|----------|------|-------------|
| `url` | string | Image URL (required; a bare string is shorthand for `{ url }`) |
| `sdf` | boolean | Treat as a signed-distance-field icon (tintable via `icon-color`) |
| `pixelRatio` | number | Source density — `2` means the file is @2x its CSS size |

```yaml
type: map
id: iconic
config:
  center: [0, 0]
  zoom: 2
images:
  poi: https://example.com/poi.png
  arrow:
    url: https://example.com/arrow.png
    sdf: true
layers:
  - id: spots
    type: symbol
    source: pts
    layout:
      icon-image: poi
```

Live, every image loads **before** layers are added, so references resolve
on first render. Images load with `crossOrigin="anonymous"` (a WebGL
texture must be untainted), so the host **must allow cross-origin access**
on every response in the chain, redirects included — a host that serves
plain `<img>` tags fine can still fail here. A failed image warns once and
the document keeps rendering. On eject the construct fully compiles (class **ejects**):
`mlym emit` fetches each URL into the document sprite and rewrites literal
references (`icon-image`, `fill-pattern`, `line-pattern`,
`background-pattern`, `fill-extrusion-pattern`) to `mlym:<name>` —
`--strict` accepts image documents. Dynamic references
(`["image", ["get", "icon"]]`) resolve live but cannot be rewritten at
compile time; emit reports them, and runtime values naming declared images
must spell `mlym:<name>` themselves. Relative URLs render live but cannot
be fetched at compile time — emit reports them as lossy, so `--strict`
refuses them.

:::caution
`mlym emit` performs a network request for **every** `images:` entry and
marker `icon:` URL in the document (bounded: 30s timeout, 20MB and
1024px-per-image ceilings). Only emit documents whose URLs you trust — the
fetched bytes are embedded verbatim into the sprite files you publish.
:::

## Terrain, sky & projection

Three document-root keys, siblings of `config:`, author the map-level 3D
scene. Each one is the style spec's own root property, in the spec's own
shape, so what you write is exactly what an ejected `style.json` carries. In
a format-v2 document they live under `style:` instead
(`style.terrain`, `style.sky`, `style.projection`).

```yaml
type: map
id: alps
config:
  center: [11.39, 47.27]
  zoom: 12
  pitch: 70
  maxPitch: 85
  mapStyle: "https://demotiles.maplibre.org/style.json"
sources:
  terrainSource:
    type: raster-dem
    url: "https://tiles.mapterhorn.com/tilejson.json"
    encoding: terrarium
terrain:
  source: terrainSource
  exaggeration: 1.5
sky:
  sky-color: "#199EF3"
  horizon-color: "#ffffff"
  fog-color: "#ffffff"
  fog-ground-blend: 0.1
  atmosphere-blend: ["interpolate", ["linear"], ["zoom"], 0, 1, 5, 1, 7, 0]
projection:
  type: globe
controls:
  navigation: true
  globe: true
  terrain: true
```

### `terrain:`

| Property | Type | Description |
|----------|------|-------------|
| `source` | string | Name of a `raster-dem` source: one in `sources:`, or one the basemap supplies (required) |
| `exaggeration` | number ≥ 0 | Vertical exaggeration (spec default `1`) |

Declare the DEM as a **named** source. Give a `hillshade` layer its own DEM
source rather than sharing the terrain's; one source serving both renders at
reduced quality. A `source` that names nothing, or a non-DEM source, warns
once and the map renders flat.

### `sky:`

| Property | Type | Description |
|----------|------|-------------|
| `sky-color` | color or expression | The sky above the horizon |
| `horizon-color` | color or expression | The band where sky meets fog |
| `fog-color` | color or expression | Fog over distant 3D terrain |
| `sky-horizon-blend` | 0–1 or expression | How far the horizon color blends up into the sky |
| `horizon-fog-blend` | 0–1 or expression | How far the horizon color blends down into the fog |
| `fog-ground-blend` | 0–1 or expression | Where fog starts: `0` at the camera, `1` at the horizon |
| `atmosphere-blend` | 0–1 or expression | Globe atmosphere opacity; draws under globe projection only |

`sky: {}` turns on MapLibre's default sky. The sky is only visible when a
pitched camera can see the horizon, and fog only affects 3D terrain.

### `projection:`

| Property | Type | Description |
|----------|------|-------------|
| `type` | `mercator` \| `globe` | `mercator` is the default |

### Runtime requirements

The live map applies each key with its MapLibre setter. Each setter is
feature-detected: on a runtime that lacks one, the document logs one console
warning naming the minimum version and keeps rendering without that effect.
It never throws.

| Key | Needs maplibre-gl | On an older runtime |
|-----|-------------------|---------------------|
| `terrain:` | 2.2.0 (`setTerrain`) | Every supported peer version has it |
| `sky:` | 4.5.0 (`setSky`) | Renders without sky or fog |
| `sky.atmosphere-blend` | 5.0.0 (draws under globe only) | No atmosphere (there is no globe) |
| `projection: globe` | 5.0.0 (`setProjection`) | Renders in mercator |
| `controls.globe` | 5.0.0 (`GlobeControl`) | The control is omitted |

The minimums come from the maplibre-gl changelog: 3D terrain arrived in
2.2.0, the spec `sky` in 4.5.0, and globe projection with its atmosphere in
5.0.0.

### On eject

All three keys are class **ejects**. `mlym emit` copies them verbatim to the
style.json root. When the basemap also defines one, the document's value
replaces the basemap's wholesale, as it does live, and emit notes the
override. A `terrain.source` that resolves to no `raster-dem` source, after
the basemap merge, is dropped with a lossy warning rather than shipped as a
style MapLibre would reject. With `--target` below a key's floor, emit keeps
the key (it still validates on 4.x) and reports the visual difference as
lossy, so `--strict --target 4.7.1` refuses a globe document. See the
[eject classes reference](/guides/eject-classes/).

## View Options

Control the camera position and orientation.

| Property | Type | Default | Range | Description |
|----------|------|---------|-------|-------------|
| `pitch` | number | `0` | 0-85 | Camera tilt angle in degrees |
| `bearing` | number | `0` | -180 to 180 | Camera rotation in degrees |
| `bounds` | array | - | - | Fit map to geographic bounds |

### Examples

#### 3D Perspective View

```yaml
config:
  center: [-122.4194, 37.7749]
  zoom: 15
  pitch: 60
  bearing: 30
  mapStyle: "https://demotiles.maplibre.org/style.json"
```

#### Fit to Bounds

```yaml
config:
  center: [-74.006, 40.7128]  # Fallback center
  zoom: 12                     # Fallback zoom
  bounds: [-74.3, 40.5, -73.7, 40.9]  # [west, south, east, north]
  mapStyle: "https://demotiles.maplibre.org/style.json"
```

## Constraints

Limit user interaction to specific zoom levels, pitch angles, or geographic areas.

| Property | Type | Description |
|----------|------|-------------|
| `minZoom` | number | Minimum zoom level (0-24) |
| `maxZoom` | number | Maximum zoom level (0-24) |
| `minPitch` | number | Minimum pitch angle (0-85) |
| `maxPitch` | number | Maximum pitch angle (0-85) |
| `maxBounds` | array | Maximum geographic bounds [west, south, east, north] |

### Example

```yaml
config:
  center: [-74.006, 40.7128]
  zoom: 12
  minZoom: 8
  maxZoom: 18
  maxBounds: [-74.3, 40.5, -73.7, 40.9]
  mapStyle: "https://demotiles.maplibre.org/style.json"
```

## Interaction Settings

Control user interaction capabilities.

| Property | Type | Default | Description |
|----------|------|---------|-------------|
| `interactive` | boolean | `true` | Enable all map interactions |
| `scrollZoom` | boolean | `true` | Enable scroll to zoom |
| `boxZoom` | boolean | `true` | Enable shift+drag box zoom |
| `dragRotate` | boolean | `true` | Enable right-drag to rotate |
| `dragPan` | boolean | `true` | Enable drag to pan |
| `keyboard` | boolean | `true` | Enable keyboard shortcuts |
| `doubleClickZoom` | boolean | `true` | Enable double-click zoom |
| `touchZoomRotate` | boolean | `true` | Enable touch zoom/rotate |
| `touchPitch` | boolean | `true` | Enable two-finger touch pitch |

### Non-Interactive Map

Create a static map for presentation:

```yaml
config:
  center: [-74.006, 40.7128]
  zoom: 12
  interactive: false
  mapStyle: "https://demotiles.maplibre.org/style.json"
```

### Custom Interaction

Disable specific interactions:

```yaml
config:
  center: [-74.006, 40.7128]
  zoom: 12
  dragRotate: false      # Disable rotation
  touchPitch: false      # Disable pitch on mobile
  doubleClickZoom: false # Disable double-click zoom
  mapStyle: "https://demotiles.maplibre.org/style.json"
```

## Map Controls

Configure which controls are displayed and where.

### Controls Structure

```yaml
controls:
  navigation: true | { enabled: true, position: "top-right" }
  geolocate: true | { enabled: true, position: "top-right" }
  scale: true | { enabled: true, position: "bottom-left" }
  fullscreen: true | { enabled: true, position: "top-right" }
  attribution: true | { enabled: true, position: "bottom-right" }
```

### Available Controls

| Control | Default Position | Description |
|---------|------------------|-------------|
| `navigation` | `top-right` | Zoom and rotation controls |
| `geolocate` | `top-right` | User geolocation button |
| `scale` | `bottom-left` | Distance scale indicator |
| `fullscreen` | `top-right` | Fullscreen toggle |
| `attribution` | `bottom-right` | Attribution text |
| `globe` | `top-right` | Globe/mercator projection toggle (maplibre-gl ≥ 5.0.0; older runtimes warn and omit it) |
| `terrain` | `top-right` | 3D terrain on/off toggle for the document's [`terrain:`](#terrain-sky--projection) (warns and is omitted when the document declares none) |

### Control Positions

- `top-left`
- `top-right`
- `bottom-left`
- `bottom-right`

### Examples

#### Enable All Controls

```yaml
controls:
  navigation: true
  geolocate: true
  scale: true
  fullscreen: true
```

#### Custom Positions

```yaml
controls:
  navigation:
    enabled: true
    position: top-left
  scale:
    enabled: true
    position: bottom-right
  fullscreen:
    enabled: true
    position: top-right
```

#### Minimal Controls

```yaml
controls:
  navigation: true
  scale: true
```

## Legend

Display a map legend showing layer information.

### Legend Structure

```yaml
legend:
  title: "Map Legend"
  position: top-left
  collapsed: false
  items:
    - color: "#ff0000"
      label: "Category 1"
      shape: circle
    - color: "#00ff00"
      label: "Category 2"
      shape: square
```

### Legend Properties

| Property | Type | Default | Description |
|----------|------|---------|-------------|
| `position` | string | `"top-left"` | Legend position |
| `title` | string | - | Legend title |
| `collapsed` | boolean | `false` | Start collapsed |
| `items` | array | - | Custom legend items |

### Legend Item Properties

| Property | Type | Required | Default | Description |
|----------|------|----------|---------|-------------|
| `color` | string | Yes | - | Item color (CSS color) |
| `label` | string | Yes | - | Item label text |
| `shape` | string | No | `"square"` | Symbol shape: `circle`, `square`, `line`, `icon` |
| `icon` | string | No | - | Icon name or URL (when `shape: icon`) |

### Examples

#### Automatic Legend

If `items` is not provided, legend items are extracted from layers with legend configuration:

```yaml
legend:
  title: "Earthquake Magnitude"
  position: top-left
```

#### Custom Legend Items

legend:

#### Line Legend

## Using Global Default Style

Define a default map style once in global config:

```yaml
config:
  defaultMapStyle: "https://demotiles.maplibre.org/style.json"

pages:
  - path: "/"
    title: "Home"
    blocks:
      - type: map
        id: map1
        config:
          center: [-74, 40]
          zoom: 12
          # mapStyle inherited from global config

      - type: map
        id: map2
        config:
          center: [139, 35]
          zoom: 12
          # mapStyle inherited from global config
```
