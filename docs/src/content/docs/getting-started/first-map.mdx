This guide walks you through the fundamentals of maplibre-yaml configuration. By the end, you'll understand how to create maps, configure their appearance, and add basic layers.

## Map structure

Every maplibre-yaml configuration has this basic structure:

```yaml
type: map # Required: identifies this as a map block
id: my-map # Required: unique identifier

config: # Map settings
  center: [-74.006, 40.7128] # [longitude, latitude]
  zoom: 12 # Zoom level
  mapStyle: "https://tiles.openfreemap.org/styles/liberty" # Basemap style URL

layers: [] # Array of layer configurations

controls: {} # Optional: map controls
```

## The host page

The YAML on its own doesn't render anything — it needs a host page with the `<ml-map>` element, the MapLibre CSS, and the web component registered. Save the YAML as `my-map.yaml` next to this `index.html`, then serve the folder (`npx serve .`) and open the address it prints:

```html
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="utf-8" />
    <!-- Without this line, phones lay the page out at desktop width and the map looks tiny -->
    <meta name="viewport" content="width=device-width, initial-scale=1" />
    <title>My map</title>
    <link
      href="https://unpkg.com/maplibre-gl@6/dist/maplibre-gl.css"
      rel="stylesheet"
    />
    <!-- Tell the browser where to find maplibre-gl -->
    <script type="importmap">
      { "imports": { "maplibre-gl": "https://unpkg.com/maplibre-gl@6/dist/maplibre-gl.mjs" } }
    </script>
    <!-- Register the <ml-map> web component -->
    <script
      type="module"
      src="https://unpkg.com/@maplibre-yaml/core@0.7/register.js"
    ></script>
    <style>
      ml-map {
        display: block;
        height: 400px;
      }
    </style>
  </head>
  <body>
    <ml-map src="./my-map.yaml"></ml-map>
  </body>
</html>
```

<Aside type="caution">
  `<ml-map>` has no intrinsic size. If you don't give it `display: block` and
  an explicit height (via CSS or an inline `style` attribute), the map renders
  into a zero-height element and you'll see nothing — even though the YAML is
  valid.
</Aside>

## The config section

The `config` section defines the initial map view:

```yaml
config:
  center: [-74.006, 40.7128] # New York City
  zoom: 12 # Street level
  mapStyle: "https://tiles.openfreemap.org/styles/liberty"

  # Optional settings
  pitch: 45 # Tilt angle (0-85)
  bearing: -17 # Rotation (-180 to 180)
  minZoom: 2 # Minimum zoom level
  maxZoom: 18 # Maximum zoom level
```

<Aside type="tip" title="Maps inside a scrolling page, on phones">
  A map that sits in the middle of a longer page catches one-finger drags on a
  phone, so the reader pans the map when they meant to scroll the page. Add
  `cooperativeGestures: true` under `config:` and the map then pans with two
  fingers (and zooms with Ctrl or ⌘ plus the scroll wheel on a computer),
  leaving one-finger swipes to the page. See the
  [cooperative gestures example](/examples/gallery/cooperative-gestures/).
</Aside>

### Coordinates

Coordinates in maplibre-yaml use **[longitude, latitude]** order (GeoJSON standard), not latitude/longitude:

```yaml
# ✓ Correct: [longitude, latitude]
center: [-74.006, 40.7128]

# ✗ Wrong: [latitude, longitude]
center: [40.7128, -74.006]
```

<Aside type="tip">
  An easy way to remember: longitude comes first because it's the X axis
  (horizontal), latitude is Y (vertical).
</Aside>

### Map styles

The `mapStyle` property accepts any MapLibre-compatible style URL:

```yaml
# OpenFreeMap Liberty: streets and labels, free, no API key (used throughout these docs)
mapStyle: "https://tiles.openfreemap.org/styles/liberty"

# MapLibre demo tiles: country outlines only, fine for world maps
mapStyle: "https://demotiles.maplibre.org/style.json"

# Self-hosted style
mapStyle: "https://your-server.com/styles/dark.json"

# MapTiler (requires API key)
mapStyle: "https://api.maptiler.com/maps/streets/style.json?key=YOUR_KEY"
```

## Adding a simple layer

Layers display data on your map. Here's a minimal circle layer:

```yaml
layers:
  - id: my-points # Unique layer ID
    type: circle # Layer type
    source: # Data source
      type: geojson
      data: # Inline GeoJSON
        type: FeatureCollection
        features:
          - type: Feature
            geometry:
              type: Point
              coordinates: [-74.006, 40.7128]
            properties:
              name: "New York"
    paint: # Visual styling
      circle-radius: 10
      circle-color: "#3b82f6"
```

Colours go in quotes. In YAML `#` starts a comment, so an unquoted
`circle-color: #3b82f6` leaves the colour empty and the layer fails
validation.

### Using your own data file

To load a GeoJSON file of your own, put it in your site folder and point the
source's `url:` at it:

```yaml
layers:
  - id: my-places
    type: circle
    source:
      type: geojson
      url: "./data/places.geojson"
    paint:
      circle-radius: 8
      circle-color: "#e63946"
```

Two rules for local paths:

- Start them with `./` (or `/` for the site root). A bare
  `data/places.geojson` is rejected by validation.
- They are resolved against the **page** (`index.html`), not against the YAML
  file. With `index.html` and `my-map.yaml` side by side and the data in a
  `data/` folder next to them, `./data/places.geojson` is right.

Files on other websites work too (`url: "https://…"`), as long as that server
allows cross-origin requests (CORS). If it doesn't, the layer stays empty and
the browser console shows a CORS error.

## Map controls

Add navigation and other controls:

```yaml
controls:
  navigation: true # Zoom +/- buttons
  scale: true # Scale bar
  fullscreen: true # Fullscreen toggle
  geolocate: true # User location button
```

## Putting it together

Here's a complete example combining everything:

```yaml
type: map
id: complete-example
config:
  center: [-98, 39]
  zoom: 4
  mapStyle: "https://tiles.openfreemap.org/styles/liberty"
  minZoom: 2
  maxZoom: 18

layers:
  - id: cities
    type: circle
    source:
      type: geojson
      data:
        type: FeatureCollection
        features:
          - type: Feature
            geometry:
              type: Point
              coordinates: [-74.006, 40.7128]
            properties:
              name: "New York"
              population: 8336817
          - type: Feature
            geometry:
              type: Point
              coordinates: [-118.243, 34.052]
            properties:
              name: "Los Angeles"
              population: 3979576
          - type: Feature
            geometry:
              type: Point
              coordinates: [-87.623, 41.881]
            properties:
              name: "Chicago"
              population: 2693976
    paint:
      circle-radius: 10
      circle-color: "#ef4444"
      circle-stroke-width: 2
      circle-stroke-color: "#ffffff"
    interactive:
      hover:
        cursor: pointer
      click:
        popup:
          - h3:
              - property: name
          - p:
              - str: "Population: "
              - property: population
                format: ",.0f" # 8336817 → 8,336,817

controls:
  navigation: true
  scale: true
```
