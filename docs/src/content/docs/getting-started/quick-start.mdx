Let's create a map showing earthquake data in under 5 minutes using the `<ml-map>` web component.

## 1. Create an HTML file

Create a new file called `index.html`:

```html
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="utf-8" />
    <!-- Without this line, phones lay the page out at desktop width and the map looks tiny -->
    <meta name="viewport" content="width=device-width, initial-scale=1" />
    <title>My First Map</title>
    <link
      href="https://unpkg.com/maplibre-gl@6/dist/maplibre-gl.css"
      rel="stylesheet"
    />
    <!-- Tell the browser where to find maplibre-gl -->
    <script type="importmap">
      { "imports": { "maplibre-gl": "https://unpkg.com/maplibre-gl@6/dist/maplibre-gl.mjs" } }
    </script>
    <!-- Register the <ml-map> web component -->
    <script
      type="module"
      src="https://unpkg.com/@maplibre-yaml/core@0.8/register.js"
    ></script>
    <style>
      body {
        margin: 0;
      }
      /* <ml-map> has no size of its own: without a height the map is invisible */
      ml-map {
        display: block;
        width: 100%;
        height: 100vh;
      }
    </style>
  </head>
  <body>
    <ml-map src="./earthquake-map.yaml"></ml-map>
  </body>
</html>
```

## 2. Create your YAML configuration

Create a file called `earthquake-map.yaml` in the same folder:

```yaml
type: map
id: earthquake-map
config:
  center: [-120, 37]
  zoom: 5
  mapStyle: "https://tiles.openfreemap.org/styles/liberty"
layers:
  - id: earthquakes
    type: circle
    source:
      type: geojson
      url: "https://earthquake.usgs.gov/earthquakes/feed/v1.0/summary/all_week.geojson"
    paint:
      circle-radius: 6
      circle-color: "#e74c3c"
      circle-stroke-width: 1
      circle-stroke-color: "#ffffff"
```

Two YAML rules that trip up almost everyone the first time: indent with
spaces (never tabs), and put colours in quotes. `circle-color: #e74c3c`
without quotes is a comment, because `#` starts a comment in YAML.

## 3. Run a local server

In the folder that holds both files, run:

```bash
npx serve .
```

Open the address it prints (usually http://localhost:3000) in your browser.
Double-clicking `index.html` instead does not work: a page opened from a
`file://` address is not allowed to fetch `earthquake-map.yaml`.

## Add interactivity

Let's make the earthquakes clickable. Update your YAML:

```yaml {18-24}
type: map
id: earthquake-map
config:
  center: [-120, 37]
  zoom: 5
  mapStyle: "https://tiles.openfreemap.org/styles/liberty"
layers:
  - id: earthquakes
    type: circle
    source:
      type: geojson
      url: "https://earthquake.usgs.gov/earthquakes/feed/v1.0/summary/all_week.geojson"
    paint:
      circle-radius: 6
      circle-color: "#e74c3c"
      circle-stroke-width: 1
      circle-stroke-color: "#ffffff"
    interactive:
      hover:
        cursor: pointer
      click:
        popup:
          - h3:
              - property: title
```

## Add live updates

Make the map refresh automatically every 60 seconds:

```yaml {6-9}
layers:
  - id: earthquakes
    type: circle
    source:
      type: geojson
      url: "https://earthquake.usgs.gov/earthquakes/feed/v1.0/summary/all_hour.geojson"
      refresh:
        refreshInterval: 60000
        updateStrategy: replace
    paint:
      circle-radius: 6
      circle-color: "#e74c3c"
```
