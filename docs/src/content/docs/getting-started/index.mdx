maplibre-yaml draws a web map from a YAML file: you describe the map, its
data and its styling, and a small script on the page does the rest. Pick the
row that matches what you want to make. Each one says where to **start**,
what to read **next**, and where to **look things up**.

Not sure what maplibre-yaml is? Read [What is maplibre-yaml?](/getting-started/introduction/)
first. Every page outside *Advanced* uses the default format (format v1).

build step; any static host (GitHub Pages included) can publish it.

## Already know MapLibre?

A maplibre-yaml document *is* a MapLibre style with the page behaviour added:
`paint:`, `layout:`, `filter:` and expressions are the
[style spec](https://maplibre.org/maplibre-style-spec/), passed through
unchanged. What maplibre-yaml adds is data loading, popups, legends, controls
and stories, written in the same file.

- **Start:** [JavaScript next to the YAML](/getting-started/introduction/#how-it-works),
  then the [MapLibre examples in YAML](/examples/gallery/): every official
  MapLibre example, with which ones the format expresses on its own
- **Then:** [Export to style.json](/guides/interactions/): `mlym emit` turns a
  document into a plain `style.json`, and
  [Export classes](/guides/export-classes/) lists what each construct becomes
- **Look up:** [JavaScript API](/integrations/vanilla-js/) ·
  [TypeScript API](/reference/api/)
