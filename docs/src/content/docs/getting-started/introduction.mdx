**maplibre-yaml** is a library that lets you create interactive web maps using YAML configuration instead of JavaScript code.

## Who Is This For?

Anyone who wants an interactive web map without writing the JavaScript for
it, for example:

- **Developers**, who want to prototype a map quickly: layers, styling and
  interactivity in one file that is fast to change.
- **Writers, journalists and researchers**, who build story maps and data
  pieces. Write the story (chapters, camera moves, layer changes) as a YAML
  file, then show it with a few lines of HTML: one `<ml-scrollytelling>`
  element in a plain page ([Story maps in plain HTML](/integrations/scrollytelling-html/)),
  or the `<Scrollytelling>` component in an Astro site
  ([Story maps in Astro](/integrations/astro-stories/)).
  No JavaScript to write.
- **People learning web mapping**, who want to focus on cartography and data
  rather than on programming.
- **People who already know MapLibre**, who want the style spec they know
  (`paint:`, `layout:`, expressions) with data loading, popups and legends
  added in the same file.

## How It Works

Instead of this JavaScript:

```javascript
const map = new maplibregl.Map({
  container: "map",
  style: "https://tiles.openfreemap.org/styles/liberty",
  center: [-90, 38],
  zoom: 3.5,
});

map.on("load", () => {
  map.addSource("rivers", {
    type: "geojson",
    data: "https://raw.githubusercontent.com/nvkelso/natural-earth-vector/master/geojson/ne_50m_rivers_lake_centerlines.geojson",
  });

  map.addLayer({
    id: "rivers",
    type: "line",
    source: "rivers",
    paint: {
      "line-color": "#2563eb",
      "line-width": 2,
    },
  });
});
```

You write this YAML:

```yaml
type: map
id: my-map
config:
  center: [-90, 38]
  zoom: 3.5
  mapStyle: "https://tiles.openfreemap.org/styles/liberty"
layers:
  - id: rivers
    type: line
    source:
      type: geojson
      url: "https://raw.githubusercontent.com/nvkelso/natural-earth-vector/master/geojson/ne_50m_rivers_lake_centerlines.geojson"
    paint:
      line-color: "#2563eb"
      line-width: 2
```

## Key Features

| Feature                | Description                         |
| ---------------------- | ----------------------------------- |
| **Declarative Config** | Define maps in YAML or JSON         |
| **Runtime Data**       | Fetch GeoJSON when map loads        |
| **Thematic maps**      | Choropleths and graduated symbols with `classify:`, legend included ([guide](/guides/thematic-maps/)) |
| **Large data**         | PMTiles, FlatGeobuf, GeoParquet and COG files from a static host ([guide](/guides/cloud-native-data/)) |
| **Live Updates**       | WebSocket, SSE, and polling support |
| **Scrollytelling**     | Narrative story maps                |
| **Accessible, translatable** | Map titles and descriptions for screen readers, translatable text ([guide](/guides/accessibility-languages/)) |
| **Web Components**     | `<ml-map>` works anywhere           |
| **Type Safety**        | Full TypeScript support             |
