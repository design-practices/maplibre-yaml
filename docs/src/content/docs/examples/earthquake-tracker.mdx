A map that keeps itself current: it reads the past week of earthquakes from
the [USGS feed](https://earthquake.usgs.gov/earthquakes/feed/v1.0/geojson.php),
fetches the feed again every minute, and redraws. Use this pattern for any
feed that returns its whole current state each time you ask.

<ExampleMap config="earthquake-tracker.yaml" height="460px" caption="USGS earthquakes of the past week, fetched again every minute" />

## How it works

**`refresh:` polls the feed.** `refreshInterval` is in milliseconds.
`updateStrategy: replace` swaps the whole layer for each response, which
fits a feed that always returns the full list. The data cache is off, so
each poll fetches the feed rather than reusing the last answer.

<YamlExcerpt config="earthquake-tracker.yaml" at={["source:"]} />

Polling pauses while the browser tab is hidden. The USGS feed allows
cross-origin requests, which a feed on another site must do for the browser
to read it ([Loading data](/guides/data-sources/) explains CORS).

**Color and size by magnitude.** Two `interpolate` expressions read `mag`:
the color runs from green at 0 to red at 6 and above, and the radius from
3 px to 24 px.

<YamlExcerpt config="earthquake-tracker.yaml" at={["circle-color:"]} />

**The popup** shows the feed's `title` and the magnitude, written with one
decimal place by `format:`.
