it, ready to copy. Start with the first four, in order; each adds one idea
to the one before. Then use the gallery to look up a specific technique.

## Use an example on your page

Save the document as a `.yaml` file in your site and load it with
`<ml-map src="map.yaml">` on an [HTML page](/integrations/web-components/),
or with the `<Map>` component in [Astro](/integrations/astro/). A document
that reads a file by a path starting with `/`, such as
`/data/classify/sample-tracts.geojson`, needs that file in your site too.
