## What to notice

- `symbol-height-offset` is a data-driven layout property: `["get", "height"]` reads each feature's own height in metres. It requires `symbol-placement: point`.
- **Requires maplibre-gl ≥ 6.6.0.** The docs site runs 6.x.
- The base style is an empty inline object with no `glyphs` URL. maplibre-gl ≥ 5.11 then draws label text with the browser's own fonts, so nothing at the style root needs authoring and the document stays pure YAML.
- The terrain comes from map-level `terrain:` and `sky:`, as in [3D terrain](/examples/gallery/3d-terrain/).
