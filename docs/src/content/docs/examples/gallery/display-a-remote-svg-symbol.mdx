Replicates the MapLibre example [Display a remote SVG symbol](https://maplibre.org/maplibre-gl-js/docs/examples/display-a-remote-svg-symbol/). Upstream fetches the SVG inside a missing-image resolver and adds it by hand. An `images:` entry does the same declaratively: the URL loads through an `<img>`, which rasterizes SVG at its intrinsic size, and the image is registered before any layer asks for it.

## What to notice

- The SVG needs an intrinsic size (`width`/`height` on the root element) and must be served with CORS headers.
- On `mlym emit` the image is fetched at compile time and merged into the document's sprite.
