## What to notice

- `updateStrategy: merge` updates the features whose `updateKey` property matches, adds new ones and keeps the rest, where upstream diffs the data by hand.
- `updateKey` names a property. USGS features have no `id` property (their id sits outside `properties`), so the key here is `url`, the earthquake's event page, which is unique to each one.
- The full pattern, with what `merge` never removes and a vehicle feed of your own: [Live data › Merge](/guides/live-data/#merge).
