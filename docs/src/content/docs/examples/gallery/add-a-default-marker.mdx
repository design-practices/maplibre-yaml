## What to notice

- `markers:` entries are DOM markers live; on `mlym emit --with-fallbacks` they lower to a symbol layer with a generated pin sprite (the format's first construct that *exports with a fallback* — see [Export classes](/guides/export-classes/)).
- `--strict` refuses marker documents: a DOM marker and a symbol layer are close, not identical, and strict means nothing visual changes.
