## What to notice

- `fill-pattern: wave` is a literal reference to the declared image — the same name works for `icon-image`, `line-pattern`, and `background-pattern`.
- On export the pattern is fetched into the document sprite and the reference rewrites to `mlym:wave`; `--strict` accepts the document because nothing is lost.
- `images:` hosts must send CORS headers (the loader uses `crossOrigin="anonymous"` for the texture upload) — unlike marker `icon:` URLs, which are plain DOM images.
