Replicates the MapLibre example [Add an animated icon to the map](https://maplibre.org/maplibre-gl-js/docs/examples/add-an-animated-icon-to-the-map/). The point and its symbol layer are YAML, hidden until the icon exists. The icon is a `StyleImageInterface`: instead of fixed pixels, `addImage` receives an object whose `render()` MapLibre calls before every frame that uses it. It redraws a canvas, copies the pixels, asks for another frame, and reports that it changed.

## What to notice

- `map.triggerRepaint()` inside `render()` keeps frames coming; return `false` from `render()` on frames where nothing changed.
- `pixelRatio: 2` treats the 200 px canvas as a 100 px icon, crisp on high-density screens.
