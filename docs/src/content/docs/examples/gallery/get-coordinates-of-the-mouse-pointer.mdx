Replicates the MapLibre example [Get coordinates of the mouse pointer](https://maplibre.org/maplibre-gl-js/docs/examples/get-coordinates-of-the-mouse-pointer/). The map is YAML; the readout is a `<pre slot="top-left">` inside `<ml-map>`. The JavaScript half is the map's own `mousemove` event, which carries the pointer's pixel position (`e.point`) and its longitude/latitude (`e.lngLat`).

## What to notice

- `e.lngLat.wrap()` folds longitudes back into −180…180 when the map shows world copies.
- For pointer events *on a layer's features*, the element's own `ml-map:layer-hover` DOM event needs no map API at all — see [Get features under the mouse pointer](/examples/gallery/get-features-under-the-mouse-pointer/).
