## What to notice

- A raster source is a `tiles:` URL template plus `tileSize`; `attribution` rides on the source and surfaces in the attribution control.
- To make the imagery the *only* thing on screen, point `mapStyle` at an empty style — here it sits above the vector basemap instead.
