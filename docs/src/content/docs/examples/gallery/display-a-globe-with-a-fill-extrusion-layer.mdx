## What to notice

- An ordinary `fill-extrusion` layer, unchanged, stands on the globe: `projection:` changes how the whole map is drawn, not how layers are written.
- `controls.globe` adds MapLibre's globe/mercator toggle (maplibre-gl 5.0.0 or later; older runtimes warn and omit it).
- Upstream's polygon rings are left open; GeoJSON requires closed rings, so each ring here repeats its first point.
