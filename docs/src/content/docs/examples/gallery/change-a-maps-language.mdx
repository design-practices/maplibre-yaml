Replicates the MapLibre example [Change a map's language](https://maplibre.org/maplibre-gl-js/docs/examples/change-a-maps-language/). The labels being translated belong to the *basemap* style, which the document references but does not author. Rewriting their `text-field` is therefore runtime work: the buttons in a corner slot point every symbol layer that reads a name at `name:<lang>`, falling back to the local name.

## What to notice

- Upstream patches three country-label layers by id; checking each symbol layer's `text-field` for a name works on any OpenMapTiles-schema basemap.
- Labels the document authors itself need no JS: a `text-field` reading `["get", ["concat", "name:", ["global-state", "lang"]]]` plus an enum parameter does it declaratively.
