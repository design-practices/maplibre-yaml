## What to notice

- `font-faces` belongs at the style root and has no dedicated YAML field. It rides the inline `mapStyle` object, the same route the [web-fonts example](/examples/gallery/style-labels-with-web-fonts/) uses for `glyphs`. That is still YAML — no page JavaScript — so this row is badged *YAML*.
- Each font face is listed under the name the layer's `text-font` asks for (`Noto Sans Regular`). Its `unicode-range` limits it to one script, and characters outside every range fall back to the glyphs URL.
- **Requires maplibre-gl ≥ 6.7.0**, the first release that renders `font-faces`. Older runtimes ignore the key and Georgian and Armenian labels do not draw. The docs site runs 6.x.
