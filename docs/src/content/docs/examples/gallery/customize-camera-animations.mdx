Replicates the MapLibre example [Customize camera animations](https://maplibre.org/maplibre-gl-js/docs/examples/customize-camera-animations/). The target marker is YAML: one named source drawn by a circle layer and a label layer. The control panel is page chrome in `<ml-map>`'s top-left slot, and its JS turns the choices into `flyTo` AnimationOptions, then moves the target through `updateLayerData()`.

## What to notice

- With an offset, the camera centres the target that many pixels away from the viewport centre — compare where the marker lands with the middle of the map.
- Both layers read one named source, so updating it through either layer id moves the circle and its label together.
- Unchecking *Animate camera motion* sets `animate: false`: the same call becomes an instant jump.
