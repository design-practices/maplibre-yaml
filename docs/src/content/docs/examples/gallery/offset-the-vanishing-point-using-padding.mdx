Replicates the MapLibre example [Offset the vanishing point using padding](https://maplibre.org/maplibre-gl-js/docs/examples/offset-the-vanishing-point-using-padding/). The pitched camera and the marker on the centre point are YAML (`markers:`). The two sidebars are page chrome in `<ml-map>`'s corner slots; opening one eases the camera's `padding` on that side to the sidebar's width, so the centre point and the horizon's vanishing point shift out from under it.

## What to notice

- Padding shrinks the part of the canvas the camera treats as the view; it also applies to later `flyTo`/`fitBounds` calls until changed.
- The sidebars are slot children, so `<ml-map>` places them and keeps the map's own gestures working around them — no absolute positioning in the page.
