Replicates the MapLibre example [Animate a point along a route](https://maplibre.org/maplibre-gl-js/docs/examples/animate-a-point-along-a-route/). Everything that is *style* is YAML: the route line, the plane icon (an `images:` entry), and a symbol layer that turns the icon by a `bearing` property. The page JS does the maths upstream borrows from Turf — bend the straight route into a great-circle arc, then walk the plane along it, writing position and heading each frame.

## What to notice

- `icon-rotate: ["get", "bearing"]` with `icon-rotation-alignment: map` is all the YAML needs for a heading-aware icon; the JS only writes the property.
- The two helpers replace `turf.along` and `turf.bearing` in a dozen lines; pulling in Turf works just as well if a page already uses it.
- The plane is a local SVG declared under `images:` — it loads before the layers, so the symbol never asks for a missing image.
