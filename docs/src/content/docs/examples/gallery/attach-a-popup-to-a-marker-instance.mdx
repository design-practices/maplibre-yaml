Replicates the MapLibre example [Attach a popup to a marker instance](https://maplibre.org/maplibre-gl-js/docs/examples/attach-a-popup-to-a-marker-instance/). The upstream `marker.setPopup(new Popup().setHTML(...))` becomes a `popup:` block on the marker — the same trust-gated structured content as layer popups, so untrusted documents can't inject markup.

## What to notice

- Marker popups use the identical content vocabulary as `click.popup` on layers — tags are allowlisted, values escaped.
- Clicking the marker toggles the popup, MapLibre's built-in behavior.
