## What to notice

- `terrain:` is a document-root key, a sibling of `config:`, in the style spec's own shape: `source` names a `raster-dem` source and `exaggeration` scales it. On export it compiles to the style.json root `terrain` unchanged.
- Terrain and hillshade read **separate** DEM sources, as upstream does — one source serving both renders at reduced quality.
- `sky: {}` turns on MapLibre's default sky, so the horizon above the pitched camera is drawn rather than left blank.
- `controls.terrain` adds MapLibre's terrain toggle, wired to the document's own `terrain:`.
- The basemap is an inline empty style (`{ version: 8, sources: {}, layers: [] }`), so the OSM raster is the only imagery, exactly like upstream.
