## What to notice

- `icon:` swaps the default pin for any image URL; `size:` scales it.
- A failed icon load falls back to the default pin with one console note — never a blank marker.
- On eject, `mlym emit --with-fallbacks` fetches each icon URL into the document sprite, so the emitted symbol layer renders the same images (markers as a whole remain a lossy fallback — dragging and popups don't compile).
