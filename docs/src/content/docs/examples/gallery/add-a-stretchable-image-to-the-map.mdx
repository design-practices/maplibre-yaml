Replicates the MapLibre example [Add a stretchable image to the map](https://maplibre.org/maplibre-gl-js/docs/examples/add-a-stretchable-image-to-the-map/). The labels and `icon-text-fit: both` are YAML. Which pixels of the background image may stretch — `stretchX`, `stretchY` — and the box the text must fit inside (`content`) are `addImage` options the `images:` block doesn't carry yet, so the page loads the two images and registers them with those zones. The layers wait hidden until then.
