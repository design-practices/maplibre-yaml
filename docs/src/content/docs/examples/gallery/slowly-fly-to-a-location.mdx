Replicates the MapLibre example [Slowly fly to a location](https://maplibre.org/maplibre-gl-js/docs/examples/slowly-fly-to-a-location/). A flight's shape — how slowly it moves, how far it zooms out before panning, its easing curve — is a set of `flyTo` options. Those are runtime choreography, not map state, so the YAML holds the map and the page JS holds the flight. The button sits in `<ml-map>`'s top-left slot.

## What to notice

- `speed: 0.2` slows the whole flight; `curve: 1` controls how far it zooms out on the way. `easing` takes any function of `t` in 0…1.
- `essential: true` keeps the animation for readers with `prefers-reduced-motion` — use it only when motion carries meaning.
