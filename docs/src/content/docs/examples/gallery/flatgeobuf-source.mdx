[FlatGeobuf](https://flatgeobuf.org/) is a compact binary file of features with an optional spatial index. A `.fgb` URL on a `geojson` source is all it takes: maplibre-yaml reads the file into the source, so layers, popups, the legend and `fitTo` behave exactly as for a `.geojson` file. Click a district; zoom in past 11 to see the stations, which are read **by view**.

## What to notice

- `type: geojson` stays the MapLibre source type; the `.fgb` file name tells maplibre-yaml to read it as FlatGeobuf. For a URL without the extension, add `format: flatgeobuf`.
- `districts` is read whole (the default, `load: all`) — fine for files up to about 10 MB.
- `points` uses `load: { mode: viewport, minzoom: 11 }`: only the features in view are read, through the file's spatial index, and re-read as the map moves. Below zoom 11 nothing is read. This needs a host with HTTP range requests (GitHub Pages, Netlify, S3, R2; not `python -m http.server`).
- `fitTo` frames the decoded districts.
- Data: synthetic and public domain (a fictional sea area), generated by `scripts/fixtures/cloud-native.py`.

More: [FlatGeobuf](/guides/flatgeobuf/) — sizes, hosting, and what the map says when a file can't be read.
