## What to notice

- Two `toggle` parameters drive two state keys; the one filter combines them with `any`/`all`.
- The layer's authored `label:` also puts a whole-layer visibility checkbox on the panel — that is `toggleable:` being consumed (set `toggleable: false` to opt a labeled layer out).
- Requires maplibre-gl ≥ 5.6 for the state-driven controls; the layer checkbox is plain visibility and works everywhere.
