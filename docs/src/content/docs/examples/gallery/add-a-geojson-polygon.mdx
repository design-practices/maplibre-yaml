## What to notice

- `region.coordinates` is an array of linear rings, exactly as in GeoJSON `Polygon` — add a second ring to cut a hole.
- The sugar node accepts only `coordinates`, `name`, and `description`; anything else is a parse error, so styling stays on the layer where it belongs.
