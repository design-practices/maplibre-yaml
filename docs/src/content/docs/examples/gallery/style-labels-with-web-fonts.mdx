## What to notice

- The inline `mapStyle` object is the widest opening in the format: anything the MapLibre style spec puts at the style root (glyphs, sprite, and today also terrain/sky/projection) can be authored there.
- It is deliberately unvalidated — the style spec is MapLibre's contract, not ours; `mlym validate` checks everything *around* it.
