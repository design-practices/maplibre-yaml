Replicates the MapLibre example [Add contour lines](https://maplibre.org/maplibre-gl-js/docs/examples/add-contour-lines/). The YAML declares the DEM, a hillshade over it, and contour line and label layers reading a vector source at `contours://{z}/{x}/{y}`. That protocol is the [maplibre-contour](https://github.com/onthegomap/maplibre-contour) plugin, registered by page JS on the maplibre module `<ml-map>` renders with. The plugin is built on the first contour tile request from the document's own `dem` source, so the DEM is declared once.

## What to notice

- Contour intervals per zoom live in the JS (`thresholds`); the line styling — major lines thicker — stays in YAML, reading the `level` property the plugin writes.
- `worker: true` computes contours off the main thread.
- Terrain: MapLibre demo tiles.
