## What to notice

- A `raster-dem` source (`encoding: terrarium` for AWS elevation tiles) plus a `hillshade` layer — no JS, no plugins.
- Add map-level `terrain:` over the same kind of source and the hillshade becomes 3D relief — see [3D terrain](/examples/gallery/3d-terrain/).
