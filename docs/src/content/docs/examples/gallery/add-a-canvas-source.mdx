Replicates the MapLibre example [Add a canvas source](https://maplibre.org/maplibre-gl-js/docs/examples/add-a-canvas-source/). A `canvas` source has no YAML form — its content is drawn by page JS every frame, so a declarative description would describe nothing. The YAML holds the map; the page animates bouncing circles on a hidden `<canvas>` and, once `mapReady()` resolves, adds a canvas source pinned to four corners plus a raster layer to draw it.

## What to notice

- `animate: true` makes MapLibre re-read the canvas every frame; set it to `false` for a static canvas to save the upload.
- The `<canvas>` sits inside `<ml-map>` *without* a `slot`, so the element leaves it where it is — hidden — while the map reads it.
- Sources added by page JS live outside the document, so `mlym emit` won't see them.
