Replicates the MapLibre example [Jump to a series of locations](https://maplibre.org/maplibre-gl-js/docs/examples/jump-to-a-series-of-locations/). The cities are a layer, so they are YAML. The tour is a sequence of events over time, so it is a few lines of page JS: a timer per stop calling `jumpTo` on the map `mapReady()` hands over. The progress readout rides a corner slot of `<ml-map>`.

## What to notice

- `jumpTo` changes the camera instantly; swap in `easeTo` or `flyTo` (see [Fly to a location](/examples/gallery/fly-to-a-location/)) for animated moves with the same arguments.
- The readout is ordinary HTML with `slot="bottom-left"`: `<ml-map>` moves it into that corner on load and stacks it with any built-in chrome.
- A tour that only needs to *frame* data on load is declarative: `config.fitTo` or `config.bounds`.
