Replicates the MapLibre example [Fly to a location](https://maplibre.org/maplibre-gl-js/docs/examples/fly-to-a-location/). Runtime camera moves have no declarative surface (by design — they're events, not state), so this page pairs a pure-YAML map with a few lines of JS through the documented `getMap()` hatch.

## What to notice

- `getMap()` on the `<ml-map>` element returns the live `maplibregl.Map` — the whole imperative API is available without ejecting from YAML.
- The division of labor is deliberate: the *map* is declarative state (YAML); a camera *flight* is an event, so it lives in event-handling code.
- The same page pattern covers `easeTo`, `jumpTo`, and `fitBounds`.
