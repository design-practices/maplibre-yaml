## What to notice

- `await mapEl.mapReady()` resolves with the live `maplibregl.Map` — the whole imperative API is available without leaving YAML, and the promise replaces the old load-listener + `getMap()` null-guard boilerplate.
- The division of labor is deliberate: the *map* is declarative state (YAML); a camera *flight* is an event, so it lives in event-handling code.
- The same page pattern covers `easeTo`, `jumpTo`, and `fitBounds`.
- The buttons are `<ml-map>` slot children (`slot="top-left"`): the element moves them into the map corner on load, so the controls sit on the map without any absolute positioning in the page.
