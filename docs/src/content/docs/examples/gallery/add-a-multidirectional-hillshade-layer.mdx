## What to notice

- `hillshade-method: multidirectional` turns the light paint properties into lists: entry *n* of `hillshade-illumination-direction`, `hillshade-illumination-altitude`, `hillshade-highlight-color` and `hillshade-shadow-color` together describe light *n*.
- **Requires maplibre-gl ≥ 5.5.0.** Older runtimes reject `hillshade-method`. The docs site runs 6.x.
- Compare the single-light [Add a hillshade layer](/examples/gallery/add-a-hillshade-layer/). The source is the same kind of `raster-dem`; only the paint differs.
