Replicates the MapLibre example [Update GeoJSON polygons](https://maplibre.org/maplibre-gl-js/docs/examples/update-geojson-polygons/). The YAML declares one named GeoJSON source and the two layers that split it by geometry type. The page seeds five rectangles with feature ids, then animates them with the source's incremental `updateData()`, which patches only the features it names instead of re-tiling the whole collection as `setData()` (and `updateLayerData()`) does.

## What to notice

- `updateData` addresses features by their top-level `id` — the seed data must carry ids.
- Named sources keep their YAML name as the MapLibre source id, so `map.getSource("rectangles")` finds it directly.
