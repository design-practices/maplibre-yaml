## What to notice

- `updateLayerData(layerId, geojson)` is the element's imperative data API — it resolves the layer's source itself, and feature-state survives the same way `refresh:` updates do.
- For data that changes on the *server*, prefer the declarative `refresh:`/`stream:` source config; this page JavaScript is for client-computed motion.
