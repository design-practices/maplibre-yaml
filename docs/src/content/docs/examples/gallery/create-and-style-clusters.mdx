## What to notice

- Clustering is entirely source configuration (`cluster`, `clusterMaxZoom`, `clusterRadius`) — the block-level `sources:` record lets three layers share one fetch.
- The `step` expressions on color and radius are the style-spec arrays verbatim.
- `filter: ["has", "point_count"]` vs `["!", ["has", "point_count"]]` splits clusters from single points, exactly as upstream.
