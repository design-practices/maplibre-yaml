## What to notice

- Clustering is source configuration: `cluster: true` groups points closer than `clusterRadius` pixels, up to zoom `clusterMaxZoom`. The source sits under `sources:` with a name, so three layers share one fetch.
- MapLibre gives each cluster two properties: `point_count` (how many points it holds) and `point_count_abbreviated` (the same, shortened to `1.2k`). The `step` expressions read `point_count` for size and color; the label shows the abbreviated one.
- `filter: ["has", "point_count"]` draws clusters only; `["!", ["has", "point_count"]]` draws the single points.
- `text-font` must name a font the basemap's glyphs include, or the counts don't draw. `Noto Sans Regular` is in the demo tiles and OpenFreeMap styles.
- `click.zoomToFeature` zooms in on a clicked cluster, here to zoom 12 (`maxZoom`). Upstream instead asks MapLibre for the zoom at which that cluster splits (`getClusterExpansionZoom`), which needs page JavaScript.
