Replicates the MapLibre example [Generate and add a missing icon to the map](https://maplibre.org/maplibre-gl-js/docs/examples/generate-and-add-a-missing-icon-to-the-map/). The points and their data-driven icon *name* (`square-rgb-<r,g,b>`) are YAML. No image by those names exists anywhere: the page answers MapLibre's request for each one by painting a square in the colour the name spells out: through `map.setMissingStyleImageResolver()` on maplibre-gl 6, which MapLibre awaits before treating the icon as missing, and through the `styleimagemissing` event on 4 and 5. The layer starts hidden so the handler is listening before the first icon request.

## What to notice

- The handler must call `addImage` synchronously; MapLibre re-checks for the image as soon as the event returns.
- maplibre-yaml's own missing-image warning defers to page handlers: an image supplied this way is never reported as missing.
