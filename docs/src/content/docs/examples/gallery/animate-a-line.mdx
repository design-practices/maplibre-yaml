Replicates the MapLibre example [Animate a line](https://maplibre.org/maplibre-gl-js/docs/examples/animate-a-line/). The line layer and its styling are YAML. The animation appends a vertex every frame and hands the whole line to `<ml-map>`'s `updateLayerData()` — the element finds the layer's source itself, so there is no `getSource(...).setData()` bookkeeping. The Pause button rides a corner slot.

## What to notice

- `updateLayerData(layerId, geojson)` targets a *layer*; YAML authors never name the internal source the layer was given.
- For data that arrives from a server rather than a loop, prefer the declarative `refresh:` or `stream:` source options — see [Add live realtime data](/examples/gallery/add-live-realtime-data/).
