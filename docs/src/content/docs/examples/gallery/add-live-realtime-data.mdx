## What to notice

- `refresh.refreshInterval` + `updateStrategy` cover the poll loop; `merge` and `append-window` strategies (with `updateKey`/`windowSize`) handle feeds that accumulate rather than replace.
- For push instead of poll, the same source takes a `stream:` block (SSE or WebSocket) — see the live-data guide.
