## What to notice

- The YAML `filter:` is the authored default; `setFilter` takes the same expression syntax at runtime.
- The declarative alternative — a `global-state` expression driven by `setGlobalStateProperty` — exists in the format but needs maplibre-gl ≥ 5.6 at runtime (tracked; see the gallery index).
- The slider is an `<ml-map>` slot child, so it sits on the map in the corner the params panel would use. (For a no-JS version of this control, see [Create a time slider](/examples/gallery/create-a-time-slider/): a `range` parameter driving a `global-state` filter.)
