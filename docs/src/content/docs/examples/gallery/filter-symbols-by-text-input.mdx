Replicates the MapLibre example [Filter symbols by text input](https://maplibre.org/maplibre-gl-js/docs/examples/filter-symbols-by-text-input/). The places and one symbol layer are YAML; the layer's `filter` keeps a place while its icon name contains a `query` state key. The params panel has no free-text control, so the search box is page chrome in a corner slot, and its JS does one thing: write the key with `setGlobalStateProperty`.

## What to notice

- Upstream hides whole layers by id; reading `global-state` in one filter replaces that bookkeeping with a single state write.
- `["in", needle, haystack]` on strings is a substring test, and an empty query matches everything.
- Needs maplibre-gl ≥ 5.6 for `global-state`. For toggles, sliders and selects, the declarative params panel needs no JS — see [Filter symbols by toggling a list](/examples/gallery/filter-symbols-by-toggling-a-list/).
