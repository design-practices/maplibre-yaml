Replicates the MapLibre example [Toggle interactions](https://maplibre.org/maplibre-gl-js/docs/examples/toggle-interactions/). YAML sets each interaction handler's *initial* state (`config.scrollZoom: false` and friends — see [Disable scroll zoom](/examples/gallery/disable-scroll-zoom/)). Switching one while the map runs is the hatch: each checkbox is named after a handler, and one delegated listener calls its `enable()` or `disable()`.

## What to notice

- The checkbox `name` *is* the handler's property on the map (`map.scrollZoom`, `map.dragPan`, …), which keeps the JS to one listener.
- The panel is `<fieldset slot="top-right">` — any element can be a slot child.
