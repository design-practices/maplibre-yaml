## What to notice

- Every paint ramp (`heatmap-weight`, `-intensity`, `-color`, `-radius`, `-opacity`) is the upstream expression verbatim — YAML's block style just makes the color stops readable.
- The cross-fade is `maxzoom: 9` + fading opacity on the heatmap against `minzoom: 7` + rising opacity on the circles; no JS involved.
