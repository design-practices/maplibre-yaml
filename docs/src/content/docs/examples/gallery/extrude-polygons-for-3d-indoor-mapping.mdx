## What to notice

- `fill-extrusion-height`, `-base`, and `-color` each read straight from feature properties with `["get", ...]` — the geometry file carries the building, the layer carries nothing but the mapping.
- The initial 3D perspective is just `config.pitch` and `config.bearing`.
