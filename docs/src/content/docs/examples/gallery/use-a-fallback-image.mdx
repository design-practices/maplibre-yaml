## What to notice

- The missing `primary-icon` is *handled* by the `coalesce` — MapLibre falls through to the next image without even a warning, exactly as upstream. (A hard-missing reference outside a coalesce gets one console note from the warn-once missing-image handler.)
- On export, literal image names inside `icon-image` rewrite to the document sprite (`mlym:fallback-marker`); the undeclared name is left alone, so the emitted style falls back identically.
- Dynamic references (`["image", ["get", "icon"]]`) resolve live but cannot be rewritten at compile time — use literal names when a document should export cleanly.
