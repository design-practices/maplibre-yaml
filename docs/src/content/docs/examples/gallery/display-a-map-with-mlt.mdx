Replicates the MapLibre example [Display a map with MLT](https://maplibre.org/maplibre-gl-js/docs/examples/display-a-map-with-mlt/). MapLibre Tiles (MLT) once needed a plugin registered before the map started. maplibre-gl now decodes them natively, and a tileset says it is MLT in its own TileJSON (`"encoding": "mlt"`). So an MLT basemap is just a style URL — no JavaScript left.

## What to notice

- Needs a maplibre-gl version with built-in MLT decoding (the docs site runs 5.24).
- No hermetic twin: there is no local MLT tileset to stand in honestly; the live docs sweep covers this page.
