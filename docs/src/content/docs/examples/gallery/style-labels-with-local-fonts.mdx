Replicates the MapLibre example [Style labels with local fonts](https://maplibre.org/maplibre-gl-js/docs/examples/style-labels-with-local-fonts/). The hatch is *inside* the YAML: an inline `mapStyle` object with no `glyphs` URL. With no glyph server to ask, MapLibre renders every label itself from fonts installed on the reader's machine, trying the `text-font` stack as CSS font families in order — here, Japanese serif faces.

## What to notice

- What renders depends on the reader's machine: a stack of several platform fonts (macOS, Linux, Windows) keeps it predictable.
- To keep a glyph server for Latin text and draw only CJK locally, use `config.localIdeographFontFamily` instead — see [Use locally generated ideographs](/examples/gallery/use-locally-generated-ideographs/).
