Replicates the MapLibre example [Filter symbols by toggling a list](https://maplibre.org/maplibre-gl-js/docs/examples/filter-symbols-by-toggling-a-list/). Upstream builds a layer per icon type in JS and wires a checkbox to each. Here each layer is declared once with a `label:`, and a labeled layer gets a visibility checkbox on the params panel automatically (`toggleable:`) — the list *is* the YAML.

## What to notice

- Set `toggleable: false` on a labeled layer to keep it off the panel.
- Icons come from the basemap's sprite (`theatre_11`, …); the four layers share one named source.
