Replicates the MapLibre example [Animate a series of images](https://maplibre.org/maplibre-gl-js/docs/examples/animate-a-series-of-images/). The `image` source — URL plus four corner coordinates — is YAML, declared inline on its raster layer. Stepping through the radar frames is a timer calling the source's `updateImage()`. Because the YAML never named the source, the page asks the layer which source it draws from.

## What to notice

- `map.getLayer(id).source` is the bridge from a YAML layer id to the source MapLibre created for it.
- `raster-fade-duration: 0` stops each frame cross-fading into the next.
- Radar frames: the upstream example's assets, served locally.
