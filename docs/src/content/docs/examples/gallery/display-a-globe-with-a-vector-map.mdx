## What to notice

- Upstream calls `map.setProjection` in a `style.load` handler; here `projection: { type: globe }` is a document-root key in the style spec's own shape, and it exports to the style.json root `projection`.
- Globe needs **maplibre-gl 5.0.0** or later. On 4.x the document warns once and renders in mercator, so it never fails silently.
