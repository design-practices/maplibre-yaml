Replicates the MapLibre example [Add a generated icon to the map](https://maplibre.org/maplibre-gl-js/docs/examples/add-a-generated-icon-to-the-map/). The symbol layer is YAML. Its icon is not a file but pixels the page computes, so it can't be an `images:` entry. The layer starts hidden (`visible: false`); the page builds a 64×64 RGBA gradient, registers it with `map.addImage`, and shows the layer with `<ml-map>`'s `setLayerVisibility`.

## What to notice

- Starting the layer hidden means MapLibre never asks for an image that doesn't exist yet — no missing-image warning, no flash.
- For an icon that *is* a file (PNG or SVG), use `images:` — see [Display a remote SVG symbol](/examples/gallery/display-a-remote-svg-symbol/).
