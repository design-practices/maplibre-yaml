## What to notice

- `ml-map:layer-hover` (and `-click`, `-data-loaded`, …) carry `{ layerId, feature, lngLat }` in `detail` — the web-component event surface is often hatch enough.
- `hover.cursor: pointer` in the YAML is what marks the layer interactive.
- The info panel is an `<ml-map>` slot child: an ordinary `<div slot="top-left">` that the element places over the map on load.
