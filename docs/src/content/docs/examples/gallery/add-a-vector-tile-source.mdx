## What to notice

- Vector sources take a TileJSON `url:` (or a `tiles:` template list); the layer picks its layer inside the tileset with `source-layer:`.
- `minzoom`/`maxzoom`, `scheme`, and `promoteId` are all available on the source when you need them.
