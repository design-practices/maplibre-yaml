## What to notice

- `config.center`, `config.zoom`, and `config.mapStyle` are the whole story — `layers:` defaults to an empty list, so the smallest useful map is five meaningful lines.
- Embed it with `<ml-map src="display-a-map.yaml">`, the Astro `<Map>` component, or eject to a plain `style.json` with `mlym emit`.
