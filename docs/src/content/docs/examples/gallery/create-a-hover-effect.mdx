## What to notice

- `hover.highlight: true` replaces upstream's mousemove/mouseleave handlers and manual `setFeatureState` calls; `generateId: true` supplies the feature ids feature-state needs on url-loaded data.
- The highlight color is currently fixed (gold) — authorable highlight styling is on the backlog.
