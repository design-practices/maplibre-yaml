## What to notice

- The `earthquakes-heat` and `earthquakes-point` layers are copied unchanged from [Create a heatmap layer](/examples/gallery/create-a-heatmap-layer/). The 3D setting is four more declarations: `projection:`, `terrain:`, `sky:`, and a hillshade layer.
- The heatmap drapes over the terrain; nothing about the layer has to know the terrain exists.
- Upstream's `maxPitch: 95` exceeds this format's `maxPitch` range (0–85), so the document uses 85.
