## What to notice

- `popup:` content is a structured list of tag blocks, not an HTML string — every value is escaped and tags are checked against an allowlist, so untrusted feature properties can't inject markup.
- `hover.cursor: pointer` replaces the two mouse-event handlers from the original.
- `property:` items read from the clicked feature; mix them with literal `str:` items freely.
