Three San Francisco places, colored by what kind of place each is, with a
legend, a highlight while the pointer is over one, and a popup with its
address and rating. Use this pattern for any points that fall into a few
categories: shops by type, stations by line, sites by status.

## How it works

**`classify:` colors the categories.** It lists each value of `category`
with its color, and `other:` colors any value not listed. It also makes the
legend: the map has no `legend:` block, so one is generated from the
classes, titled with the layer's `label:`.

<YamlExcerpt config="interactive-points.yaml" at={["classify:"]} />

`classify:` compiles to the MapLibre `match` expression you could write in
`circle-color` yourself. Write the `match` by hand only when you need
something `classify:` doesn't do; you then lose the generated legend and the
highlight below. [Thematic maps & legends](/guides/thematic-maps/) covers
categories, palettes and numeric classes.

**The hover highlight.** `highlight: true` recolors the point under the
pointer. It needs feature ids, which `generateId: true` on the source
provides. (Without it, maplibre-yaml turns `generateId` on itself and says
so in the browser console.)
