## Key Concepts

### Categorical colors with match expression

Different colors for each category:

```yaml
circle-color:
  - match
  - ["get", "category"]
  - "government"
  - "#6366f1"        # Indigo for government
  - "landmark"
  - "#f59e0b"        # Amber for landmarks
  - "sports"
  - "#22c55e"        # Green for sports
  - "#6b7280"        # Gray fallback
```

### Rich multi-line popups

Popups can contain multiple elements with mixed content:

```yaml
interactive:
  click:
    popup:
      - h3:
          - property: name
      - p:
          - str: "📍 "
          - property: address
      - p:
          - str: "⭐ "
          - property: rating
          - str: " / 5"
```

### Hover cursor

Change cursor on hover to indicate interactivity:

```yaml
interactive:
  hover:
    cursor: pointer    # Shows pointer cursor on hover
```

### Popup structure

Each popup item is an object with:
- **Tag**: HTML element (`h3`, `p`, `div`, etc.)
- **Content**: Array of content items that can be:
  - `{ str: "text" }` - Static text
  - `{ property: "name" }` - Feature property value

### Emoji in content

Unicode characters work in popup text:

```yaml
- p:
    - str: "📍 "
    - property: address
```

## Advanced: Hover effects

To highlight the point under the pointer, add `highlight: true`: the layer's
colour changes while the pointer is over a feature, with no paint to write.

```yaml
interactive:
  hover:
    cursor: pointer
    highlight: true
```

To change something else on hover, such as the size, reference the hover
state in the paint value yourself, a MapLibre `feature-state` expression:

```yaml
paint:
  circle-radius:
    - case
    - ["boolean", ["feature-state", "hover"], false]
    - 18                       # Grow on hover
    - 12
```

Hover state needs feature ids: add `generateId: true` (or `promoteId`) to the
source. See [Hover](/schema/interactivity/#hover) for the details.
