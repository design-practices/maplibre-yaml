Four thematic maps, each written as one `classify:` block on an ordinary
layer. Every one compiles to a plain MapLibre expression and generates its
own legend. This page gives the complete document for each map; how
`classify:` works, and every option, is in
[Thematic maps & legends](/guides/thematic-maps/).

## Choropleth — quantile classes from the data

Median household income by tract, in five quantile classes (the same number
of tracts in each). The breaks are computed when the GeoJSON loads. The
document declares no legend, so one is generated, showing the real class
edges formatted as currency. Tracts with no value are light grey: in this
sample that is `null`, a missing property, `""` and `"n/a"`. Numeric
strings, such as the `"48200"` a CSV export leaves behind, count as numbers.

## A rate — cases per 100,000 residents

`normalize: population` and `multiply: 100000` turn a count into a rate, and
the natural breaks are computed on the rate. The tract with no residents is
no data (grey), not an infinitely high class.

<ExampleMap config="classify/rate.yaml" height="460px" caption="Synthetic sample tracts" />

## Graduated symbols — natural breaks, color and size

World cities by population in five natural-breaks (jenks) classes. One block
drives both `circle-color` and `circle-radius` from the same breaks.

<ExampleMap config="classify/graduated.yaml" height="420px" caption="Natural Earth populated places (public domain)" />

## Categories over vector tiles

The demo tiles' countries colored by continent with `okabe-ito`, a
palette that stays distinct for readers with color blindness. Categories
compile to a `match` and need no data scan, so they work on a basemap's
vector tiles; values not listed (Antarctica) take the `other:` color.

<ExampleMap config="classify/categories.yaml" height="400px" />

## Export

`mlym emit choropleth.yaml` writes a style.json whose `fill-color` is the
compiled `step` expression, with the breaks computed from the data at export,
and whose layer `metadata["maplibre-yaml:classify"]` records the classes. It
opens in Maputnik and renders in any MapLibre map, with no maplibre-yaml
needed. More in [Export to style.json](/guides/export/).

## Data and reference

- The tract maps read [sample-tracts.geojson](https://docs.maplibre-yaml.org/data/classify/sample-tracts.geojson),
  synthetic tracts made for these examples; the graduated map reads
  [world-cities.geojson](https://docs.maplibre-yaml.org/data/classify/world-cities.geojson).
  The documents read them from `/data/classify/` on this site: to run a
  document on yours, download the file into the same folder, or replace
  its `url:` with the full address.
- Every `classify:` key: [the layers reference](/reference/yaml/layers/#classify).
