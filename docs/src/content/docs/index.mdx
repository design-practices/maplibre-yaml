## One file, one map

This map of the past week's earthquakes, sized by magnitude, is the YAML
below it. Click a circle to see where it happened.

<LiveMap
  src="/configs/earthquakes.yaml"
  height="400px"
  caption="Earthquakes of the past seven days, from the USGS live feed"
/>

```yaml title="map.yaml"
type: map
id: earthquake-map
config:
  center: [-160, 20]
  zoom: 1
  mapStyle: "https://tiles.openfreemap.org/styles/liberty"
layers:
  - id: earthquakes
    type: circle
    source:
      type: geojson
      url: "https://earthquake.usgs.gov/earthquakes/feed/v1.0/summary/all_week.geojson"
    paint:
      circle-radius: ["interpolate", ["linear"], ["get", "mag"], 1, 2, 7, 20]
      circle-color: "#e74c3c"
      circle-opacity: 0.7
      circle-stroke-width: 1
      circle-stroke-color: "#ffffff"
    interactive:
      hover:
        cursor: pointer
      click:
        popup:
          - h3:
              - property: place
          - p:
              - str: "Magnitude "
              - property: mag
                format: { max-fraction-digits: 1 }
controls:
  navigation: true
  scale: true
```

Save it as `map.yaml`, put `<ml-map src="map.yaml"></ml-map>` on a web
page, and the page shows this map. The
[quick start](/getting-started/quick-start/) builds it with you in a few
minutes.

## Why maplibre-yaml?

<CardGrid stagger>
  <Card title="No JavaScript to write" icon="pencil">
    The basemap, your data, its styling, popups, legends and story chapters
    all go in one YAML file, which checks itself and tells you which line is
    wrong.
  </Card>
  <Card title="Live data" icon="rocket">
    Data loads when the page opens, so the map shows today's version of a
    feed, and it can refresh itself while the page stays open.
  </Card>
  <Card title="All of MapLibre" icon="setting">
    Layers use the MapLibre style spec as it is: expressions, data-driven
    styling, 3D terrain and globe. You can export a map to a plain
    `style.json`.
  </Card>
  <Card title="Works in any page" icon="puzzle">
    A plain HTML page from a CDN, an Astro site, or a React, Vue or Svelte
    app: the `<ml-map>` element is the same in each.
  </Card>
</CardGrid>
