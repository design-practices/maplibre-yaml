## Why maplibre-yaml?

<CardGrid stagger>
  <Card title="No JavaScript Required" icon="pencil">
    Define your entire map in YAML: layers, data, popups, legends and stories.
    For anyone who wants a web map without writing the code for it, and for
    developers who want to prototype quickly.
  </Card>
  <Card title="Runtime-First" icon="rocket">
    Data is fetched when your map loads, so it can update live. The script is
    about 175 KB gzip (plus maplibre-gl), and readers for large-data formats
    download only when a map uses them.
  </Card>
  <Card title="Full MapLibre Power" icon="setting">
    Access all MapLibre GL features: expressions, data-driven styling, 3D
    terrain, and more.
  </Card>
  <Card title="Framework Agnostic" icon="puzzle">
    Use with vanilla JavaScript, Astro, or any framework via web components.
  </Card>
</CardGrid>

## Quick Example

```yaml
type: map
id: my-first-map
config:
  center: [-90, 38]
  zoom: 3.5
  mapStyle: "https://tiles.openfreemap.org/styles/liberty"
layers:
  - id: rivers
    type: line
    source:
      type: geojson
      url: "https://raw.githubusercontent.com/nvkelso/natural-earth-vector/master/geojson/ne_50m_rivers_lake_centerlines.geojson"
    paint:
      line-color: "#2563eb"
      line-width: 2
controls:
  navigation: true
  scale: true
```
