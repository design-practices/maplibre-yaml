A map from YAML is already pannable and zoomable. This guide adds the parts
that answer a reader's "what is this?": a popup when they click a feature, a
highlight and a tooltip while they point at one, a camera that moves to what
they chose, and the buttons around the map. It all goes in a layer's
`interactive:` block or the document's `controls:` block, with no JavaScript.

Complete documents (they start with `type: map`) run as printed. Snippets
that start with `popup:`, `interactive:` or `controls:` are one part of a
document.

## Show a popup on click

Give the layer an `interactive:` block with a `click.popup`. The popup is a
list of HTML elements, and each one lists what goes inside it:

Click New York and the popup reads **New York** over "Population:
8,336,817". `cursor: pointer` turns the pointer into a hand over the circles,
so readers can tell they are clickable. One popup is open at a time; clicking
elsewhere closes it.

## Choose what the popup shows

`- h3: [{ property: name }]` becomes `<h3>New York</h3>`: the key is the
element, and its list holds **items** whose output is joined inside it.

| Item | Shows |
|------|-------|
| `str: "Population: "` | The text as written |
| `property: population` | The clicked feature's `population` property |
| `property: nickname` with `else: "none recorded"` | The fallback when the property is missing or `null` (without `else`, nothing) |
| `property: population` with `format: { … }` | A formatted number ([below](#format-numbers)) |
| `href: "https://…"` with `text: "Read more"` | A link with that text (the URL itself without `text`) |
| `src: "https://…/photo.jpg"` with `alt: "…"` | An image |

```yaml
popup:
  - h3: [{ property: name }]
  - p:
      - str: "Nickname: "
      - property: nickname
        else: "none recorded"
  - p:
      - href: "https://en.wikipedia.org/wiki/New_York_City"
        text: "Read about it on Wikipedia"
  - p:
      - src: "https://maplibre.org/img/maplibre-logo-big.svg"
        alt: "MapLibre logo"
```

- **Elements:** `h1`–`h6`, `p`, `span`, `div`, `strong`, `em`, `code`, `pre`,
  `a`, `img`, `ul`, `ol`, `li`, `blockquote`, `hr` and `br`. Any other key is
  skipped with a console warning. Elements don't nest: a `ul:` can't contain
  `li:` entries. Put links and images inside `p:` or `div:`.
- **Text is always text.** Property values and `str` are shown as text, never
  as markup, so data can't inject HTML into your page.
- **Links** take an absolute URL (`https://`, `mailto:`, `tel:`) or a path on
  your site (`/about`, `notes.html`, `#top`); any other scheme, such as
  `javascript:`, is shown as plain text. A link opens in a new tab unless you
  write `target: _self` (or `_parent`, `_top`). Its URL is fixed text: it
  can't be built from a property.

Every popup key is in the [layer reference](/reference/yaml/layers/#interactive).

## Format numbers

A `property` item with `format:` formats a number in the reader's language.
The options are those of MapLibre's
[`number-format`](https://maplibre.org/maplibre-style-spec/expressions/#number-format)
expression, the same ones a label's `text-field` uses:

| Option | What it does | Example |
| --- | --- | --- |
| `locale` | The language to format for. Default: the page's language, then the browser's | `de-DE` |
| `currency` | Format as money | `EUR`, `USD`, `JPY` |
| `unit` | Add a unit (ignored with `currency`) | `kilometer`, `percent`, `celsius` |
| `min-fraction-digits` | At least this many decimals | `2` |
| `max-fraction-digits` | At most this many decimals (rounds) | `0` |

```yaml
popup:
  - p:
      - str: "Population: "
      - property: population
        format: { max-fraction-digits: 0 }                  # 8,336,817
  - p:
      - str: "Median rent: "
      - property: rent
        format: { currency: EUR, max-fraction-digits: 0 }   # €1,240
  - p:
      - str: "Area: "
      - property: area_km2
        format: { unit: kilometer, max-fraction-digits: 1 } # 12.5 km
```

- **The page's language decides.** The `lang` on `<ml-map>` or on `<html>`
  comes first, then the browser's. On a page with `<html lang="de">` the
  population reads "8.336.817" and the rent "1.240 €". Write `locale: en-US`
  in a format to fix one regardless of the page.
- **Text that reads as a number** (`"54000"`, as CSV-derived data often has)
  is formatted like the number; other text (`"n/a"`) is shown as stored.
- **Without `format:`** a property is shown exactly as stored, so years and
  ids (`1999`, `10012`) are never grouped.
- A d3-style string such as `format: ",.0f"` also works (`,` groups
  thousands, `.Nf` keeps N decimals) and follows the page's language too.

The same formatter is exported for your own code as
`formatNumber(value, options, defaultLocale)` from `@maplibre-yaml/core`.
A [classified](/guides/thematic-maps/) layer's legend takes the same options.

## Respond to hover

The `hover:` part of `interactive:` takes three things, alone or together:

- **`cursor`**: the CSS cursor over a feature, usually `pointer`.
- **`highlight: true`**: recolours the feature under the pointer.
- **`popup`**: a tooltip, in the same format as `click.popup`, shown while the
  pointer is over a feature and gone when it leaves. It has no close button.
  A popup opened by a click stays, and hover tooltips wait until it is
  closed. Touch screens have no hover: a tap opens `click.popup`.

`highlight` needs an id on each feature. `promoteId` names a property that is
different for every feature (`STATE_ID` here), which keeps the same id when
the data refreshes. `generateId: true` numbers the features instead. On a
layer whose data is written in the YAML, leaving both out generates ids with
a console warning; a file loaded from `url:` has no ids unless the file has
them, and the console says "needs feature ids".

`highlight` changes the layer's main colour (`fill-color` here), and works on
[classified](/guides/thematic-maps/) layers too. If that colour is already an
expression of your own, `highlight` leaves it alone and warns; to choose the
highlight colour yourself, use `["feature-state", "hover"]` in the paint, as
in [Custom highlight styling](/schema/interactivity/#custom-highlight-styling).
Gallery: [Create a hover effect](/examples/gallery/create-a-hover-effect/),
[Display a popup on hover](/examples/gallery/display-a-popup-on-hover/).

## Move the camera to a feature

Two click actions move the map to what the reader picked. They work with or
without a popup; with one, the popup opens first and travels with the map.

```yaml
interactive:
  click:
    flyTo:
      zoom: 8          # optional; center defaults to the clicked point
      duration: 600    # optional, milliseconds
```

```yaml
interactive:
  click:
    zoomToFeature:
      padding: 40      # pixels around the feature (optional)
      maxZoom: 12      # don't zoom closer than this (optional)
```

`flyTo` centres on the clicked point (or a `center:` you give) at a zoom you
choose, which suits points. `zoomToFeature` fits the clicked feature's own
outline in view, which suits areas and lines of different sizes.

## Add map controls

`controls:` adds MapLibre's buttons around the map. `true` puts a control in
its usual corner; an object picks the corner:

```yaml
type: map
id: with-controls
config:
  center: [-74.006, 40.7128]
  zoom: 11
  mapStyle: "https://tiles.openfreemap.org/styles/liberty"
controls:
  navigation: true          # zoom in/out and compass, top-right
  scale: true               # distance scale, bottom-left
  fullscreen: true          # top-right
  geolocate:                # "show my location", asks the reader's permission
    enabled: true
    position: top-left
```

| Control | What it adds | Default corner |
|---------|--------------|----------------|
| `navigation` | Zoom buttons and a compass that resets the bearing | `top-right` |
| `scale` | A distance scale | `bottom-left` |
| `fullscreen` | Fullscreen toggle | `top-right` |
| `geolocate` | Show the reader's location (the browser asks first) | `top-right` |
| `globe` | Globe / flat map toggle (maplibre-gl 5 or later) | `top-right` |
| `terrain` | 3D terrain on/off, for a document with [`terrain:`](/schema/map-config/#terrain-sky--projection) | `top-right` |
| `attribution` | The data credits, with `compact` and `customAttribution` options | `bottom-right` |

The corners are `top-left`, `top-right`, `bottom-left` and `bottom-right`.
Without an `attribution` entry, MapLibre's own attribution still shows in
the bottom-right corner: crediting the map data is a licensing obligation for
most map tiles.

Button labels ("Zoom in", "Zoom out" …) come from MapLibre's `locale:` keys,
so a `config.locale` table translates them along with everything else the
library draws ([Show the map in another language](/guides/accessibility-languages/#show-the-map-in-another-language)).

To turn off ways of moving the map instead (scroll zoom, rotation, a fully
static map), see [Interaction settings](/schema/map-config/#interaction-settings).

## Troubleshooting

- **Clicking does nothing.** Popups, hover and click actions need an
  `interactive:` block on the layer itself. Check that it is indented under
  the layer, beside `paint:`.
- **The popup shows a label but no value.** The property name doesn't match
  the data: names are case-sensitive (`Name` is not `name`). Add
  `else: "…"` to see when a value is missing.
- **Nothing highlights, and the console says "needs feature ids".** Add
  `promoteId` or `generateId: true` to the source ([above](#respond-to-hover)).
- **Highlight warns that the colour is already an expression.** Use
  [custom highlight styling](/schema/interactivity/#custom-highlight-styling)
  instead.

More: [Troubleshooting](/troubleshooting/).

## Reacting from your own JavaScript

Popups, highlights and camera moves need no code. To do something else when
a feature is clicked (update a chart, fill in a side panel), listen for the
element's events. They fire for features of a layer with an `interactive:`
block:

```js
const map = document.querySelector("ml-map");
map.addEventListener("ml-map:layer-click", (event) => {
  const { layerId, feature, lngLat } = event.detail;
  console.log(layerId, feature.properties);
});
```

`ml-map:layer-hover` carries the same details for hover. Every event is in
[`<ml-map>` events](/reference/elements/#ml-map-events). For a named event
with a payload you choose, see `click.emit` (host event) in
[Interactivity](/schema/interactivity/#emit).

<Aside type="note" title="Popups and hover stay on the page">
  Popups, hover and click actions are page behaviour, not part of a MapLibre
  style: `mlym emit` leaves them out of the exported `style.json` and says
  so. [Export to style.json](/guides/export/) shows how to attach them to an
  exported map with `attachInteractions`.
</Aside>
